  Phase 1.
- Fixed a heredoc-read exit-status hazard the plan did not anticipate: a plain
  `read -r -d '' VAR <<'EOF' ... EOF` returns exit 1 on reaching the heredoc's EOF (no literal NUL
  delimiter present), which would abort sourcing under `state-write.sh`'s `set -euo pipefail` the
  moment Phase 2 adds the source line. Fixed with a trailing `|| true` on the `read` invocation
  inside the library itself, so a plain `source`/`.` is safe under `-e` without requiring every
  consumer to wrap the source call in its own `if ! ...; then` guard (confirmed the same hazard
  reproduces against the pre-existing `lib/file-scope-overlap.sh`, whose consumers all DO use the
  `if ! . FILE; then` guard -- this library's `|| true` fix is the alternative mitigation, chosen
  so Phase 2's plain `source` line beside `lib/common.sh` needs no special-casing).
