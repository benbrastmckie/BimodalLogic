## The demand change, stated so it is not re-litigated

`TailStable` was `Φ_back L₀ = L₀ ∧ Φ_fwd R₀ ∩ R₀fwd = R₀`. It is now

```
(∀ r ∈ Finset.range G.NBnat,
    G.iterBack (-G.NB - r) (G.liveAt (-G.NB - r)) G.NBnat = G.liveAt (-G.NB - r))
∧ (∀ r ∈ Finset.range G.NFnat,
    G.iterFwd (G.NM + G.NF + r) (G.liveAt (G.NM + G.NF + r)) G.NFnat
      ∩ G.fwdLiveAt (G.NM + G.NF + r) = G.liveAt (G.NM + G.NF + r))
```

and `TailStableRaw` is the same without the filter. Four facts about it:

- **The `r = 0` instances are the old conjuncts verbatim** — `tailStable_back`, `tailStable_fwd`,
  `tailStableRaw_back`, `tailStableRaw_fwd`. Every theorem previously stated from `hTS.1` / `hTS.2`
  now routes through one of these and is otherwise unchanged. Nothing was weakened.
- **`TailStableRaw` was strengthened in the same way, deliberately.** Had it not been,
  `tailStable_of_raw` would have become false. `FixtureStable`'s `not_tailStableRaw` and
  `not_tailStable_cert` are re-proved through the projections; both statements are unchanged.

  earns its factor: `-2 * G.NB ≤ -G.NB - r` holds exactly because `r < G.NB`). `#guard decide
  triv.TailStable` still passes. The checker's cost goes from 2 `Φ` applications to
