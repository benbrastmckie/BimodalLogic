## The scope of the failure, for anyone tempted to repair it with a bound

Recorded in `NoCertificate.lean`'s own docstring and repeated here because it governs Stage 2:
(C2') is a demand about **every** thread of a finite, eventually periodic presentation, so every
cycle reachable in the periodic region is a thread. Any target whose countermodels must contain a
cycle with an exit under a pending eventuality therefore has no certificate. `k` in the proof is
defined *from* the family's own `lassos.length * perFwd`, so raising any of the family's numbers
raises the pigeonhole with it. **No bound repairs this.** Weakening (C2') to some restricted thread
class is also closed off while `plusRefutes_of_certifies` is to survive unchanged: the soundness
direction reads (C2') at exactly the threads the joint countermodel construction builds.
