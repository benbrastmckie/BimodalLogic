## Key Findings from Analysis

1. **Pointwise 1-var NF agreement + orderings is NOT sufficient for n-var NF agreement** — interval type data is essential (counterexample: different interval type distributions with same endpoint NFs).

2. **Zone_match_witness places u' in the correct zone relative to (x,t) but does NOT control sub-interval types** — a type in (x,u) might appear in (u',t') rather than (x',u').

3. **The depth-k 1-var NF of u encodes neighborhoods (above/below) but NOT interval-restricted types** — `interval_nf_types M k x u` cannot be derived from NFs of x and u alone.

4. **All recursive approaches hit the same barrier** — adding a variable via zone matching produces a point whose position relative to OTHER zone-matched points is undetermined within the same interval.

5. **The game composition (Composition.lean) DOES solve this** — by splitting strategies at the pivot point and maintaining the invariant on each sub-interval independently. This is the standard GHR93 proof technique.
