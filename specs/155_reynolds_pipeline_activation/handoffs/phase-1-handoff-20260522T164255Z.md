## Key Decisions

1. Used `h_enough : 1 + 3 * n <= rounds_r1` instead of `4 + 3 * n <= rounds_r1` from report 18. The weaker bound works because `1 + 3 * (n+1) = 4 + 3 * n`, so the succ case derives `4 + 3 * n <= rounds_r1` from omega. The base case only needs `1 + 3 * 0 = 1 <= rounds_r1`, which is trivially satisfied.
