**Goal**: `stavi_temporal_truth_mu M atomMap r (Sum.inr gamma_rdef) X`

**Root Cause**: The theorem statement is incorrect for arbitrary X. Specifically:
- The forward direction constructs a gap from the FO table
- The FO table gives `stavi_temporal_truth M atomMap v X` at complement points v (non-mu, on M.carrier)
- The theorem requires `stavi_temporal_truth_mu M atomMap r (Sum.inr gamma) X` (mu-relativized, at gap)
- For X = `.base (.atom a)`: atoms evaluate to False at gaps via `extendedStructure.interp`, so X^mu(gamma) = False, but X(v) = True at complement points. The forward direction cannot produce X^mu(gamma).

**Impact**: The theorem is used in `left_formula_gap_detection` at specific X values:
1. X = `.base Formula.top` -- X^mu(gamma) = True (trivial), and the result is discarded anyway
2. X = `.conj B (.stavi_untl A B)` -- needs B^mu(gamma) which CAN be False when B is an atom
3. X = `.conj B (.std_untl A B)` -- same issue

**However**: Callers only USE `X.2` (the temporal component), discarding B^mu(gamma). So the actual mathematical need is U'(A,B)^mu(gamma), NOT the full X^mu(gamma).
