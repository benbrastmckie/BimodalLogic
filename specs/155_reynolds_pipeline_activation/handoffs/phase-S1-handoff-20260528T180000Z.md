## The Remaining Gap

### Precise Goal State

At each sorry site, the goal is: given u in M (or u' in M') satisfying a depth-k 3-var NF `sub_nf` at (u, x, t) (resp. (u', x', t')), find the matching witness in the other model.

Available hypotheses at the sorry:
- `h_nf_x`, `h_nf_t`: depth-(k+1) 1-var NF agreement at x/x', t/t'
- `h_interval_*`, `h_above_max`, `h_below_min`: depth-(k+1) zone data
- `ih_result`: depth-k 2-var NF agreement at (x,t)/(x',t')
- `h_atom_agree`: atom agreement at 2 vars

### Why It's Hard

**Step 1** (doable): Find u' in M' with same depth-(k+1) 1-var NF tau in the same zone, using interval/above/below data.

**Step 2** (the gap): Show nf_eval_nf M' k 3 (u', x', t') sub_nf where sub_nf = nf_characteristic M k 3 (u, x, t). This requires the depth-k 3-var NFs at (u,x,t) and (u',x',t') to agree.

The 3-var NF agreement requires (at depth k >= 1):
- Atom agreement at 3 vars: provable from zone + 1-var NF agreement
- Quantifier transfer at depth (k-1) for 4 vars: needs matching of a 4th point w/w' in the correct zone of the 3-point configuration, which requires interval type data for sub-intervals of the 3-point config.

The sub-interval data is NOT derivable from the original 2-point interval hypotheses. This is the "sub-interval problem" documented in reports/43_bridge-lemma-resolution.md.

### Why Standard Approaches Fail

1. **Direct induction on k**: IH gives 2-var bridge at depth k; need 3-var bridge at depth k.
2. **Generalized induction on n**: Requires interval data for all sub-intervals at each n+1 step.
3. **nf_agreement_monotone**: Varies depth at fixed n; need n-var from 1-var.
4. **Fraisse compression** (depth-0 at many vars -> depth-k at few vars): Requires matching at each round where Duplicator has a strategy. Strategy construction requires zone-specific matching, which needs sub-interval data.

### Resolution Path

The correct approach is the **Fraisse game argument** (Option A from reports/43_bridge-lemma-resolution.md):

1. Define a k-round game where Spoiler challenges with a new point, Duplicator responds with a matching point (same zone + same depth-(k+1) 1-var NF).

2. Prove: Duplicator's strategy exists (from the bridge lemma hypotheses -- zone matching + NF matching from interval/above/below data).

3. Prove: After k rounds, the (2+k)-point configuration has depth-0 agreement at (2+k) vars (from the matched points' NFs + orderings).

4. Prove **the Fraisse compression theorem**: For all j >= 0 and n >= 0, depth-j NF agreement at n vars AND existential transfer of depth-j NFs for (n+1)-var extensions, iterated k times, gives depth-(j+k) NF agreement at n vars.

This theorem is the converse of `nf_agreement_monotone` in some sense. It says: k rounds of back-and-forth (which provide existential transfer at each level) compress into k additional levels of quantifier depth agreement.

The critical distinction from the approaches that fail: the game argument does NOT require sub-interval data at intermediate steps. Instead, the matching at each round uses ONLY the original hypotheses. The sub-intervals are handled by the fact that the original interval/above/below data provides matching in any zone of the 2-point configuration (not sub-zones of later configurations).

Wait -- that's the same issue. At round 2 (adding w to (u, x, t)), Spoiler picks w in some zone of the 3-point config. Duplicator needs to respond with w' in the same zone. The zone might be (x, u), which is a sub-interval of (x, t). The original interval data gives matching in (x, t), not in (x, u).

**Resolution of the resolution**: After round 1, u and u' have the same depth-(k+1) 1-var NF tau. tau encodes which depth-k 2-var NFs at (*, u) are realizable. In particular, for any w in zone (x, u) in M, the pair (w, u) has some depth-k 2-var NF. This 2-var NF is realizable at u' in M'. So w' exists with the same depth-k 2-var NF at (w', u'). The 2-var NF includes the ordering (w' < u'), so w' is below u'. But is w' above x'?

The 2-var NF at (w, u) does NOT encode w's relationship to x. So w' might be anywhere below u' (including below x').

To place w' between x' and u': we need additional information -- specifically, we need to use x's depth-(k+1) 1-var NF as well. The pair (w, x) has some depth-k 2-var NF. Since x' has the same depth-(k+1) 1-var NF, this NF is realizable at x'. So w'_x exists with w'_x > x'. But w'_x != w'_u in general.

**The game resolution**: Duplicator doesn't need to place w' in a specific sub-interval. She needs w' to produce the same GAME OUTCOME after all remaining rounds. If there are m rounds remaining, the game outcome depends on depth-m agreement. At depth 0 (last round), only atoms matter, and atoms at w' are determined by w''s 1-var NF + its orderings with the matched points.

The problem is that at depth > 0, the game outcome depends on further extensions, which depend on w''s zone. And the zone is not controlled.

I believe the game argument works because at each subsequent round, the "depth budget" decreases by 1, and eventually at depth 0 the zone doesn't matter (only atoms = predicates + orderings relative to named points, and orderings are determined by the zone we CAN control at depth-(k+1) from the original hypotheses).

But making this formal requires a game definition + winning strategy construction + the compression theorem. Estimated: 300-500 lines of new infrastructure.
