### Sorry 2 Analysis (Direction 1, d <= t')

**Finding**: Sorry 2 (line ~1900, the `d <= t'` direction in h_d_unique) CANNOT be closed using the Direction 1 cross-structure argument because h_d_unique is universally quantified over ALL t' with rank-r agreement, not just game responses.

**Detailed analysis**:

The GHR93 Direction 1 argument (cross-structure, no K^-) works as follows:
1. Assume d-bar < d (game response below infimum)
2. Cofinal failure at d-bar gives u with d-bar < u <= d, mu(u), formula A on (a_n, y'), not-A(u)
3. Play game: Spoiler picks p_u from N, Duplicator responds with b from M
4. Order: d-bar < u gives c-bar < extendPoint(b) (from game tuple position correspondence)
5. c-bar = inf(S_C^M) and extendPoint(b) > c-bar gives cont_holds_cross(b)
6. cont_holds_cross(b): A on (a_n, y') implies A(b in M). So A(b) = TRUE.
7. Formula agreement: A(b in M) <-> A(u in N). So A(u) = TRUE. Contradiction with not-A(u).

**Why this fails for h_d_unique**: In step 4, the order correspondence uses positions (1,2) in the game tuple. Position 1 on the M-side is c-bar (Spoiler's selection). Position 1 on the N-side is the game RESPONSE d-bar. The argument requires d-bar < u, which follows from cofinal failure applied AT d-bar.

In h_d_unique, t' is an arbitrary element with rank-r agreement, not the game response. When we play the game with c as selection, the N-side response at position 1 is some element w (NOT t'). The order d-bar < u becomes w < u, which is NOT guaranteed (w might not equal t', and we can't prove w = d without h_d_unique -- circular).

**Conclusion**: h_d_unique as formulated is too strong. Per the plan (v17), the fix is to remove h_d_unique and inline the Claim 1 argument directly in d_consistency_left/right, where the game response IS in scope.
