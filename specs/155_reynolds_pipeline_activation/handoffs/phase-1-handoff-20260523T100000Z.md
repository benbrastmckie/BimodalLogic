### Step 4: K-neg-D_M(c_inf) = TRUE in M at rank r

Need: negation(Since(top, D_M)(c_inf)) at rank r in M.
Since(top, D_M)(c_inf) = exists s < c_inf, mu(s), top(s), forall u in (s, c_inf), mu(u) -> D_M(u).
To show FALSE: for any carrier s < c_inf, there exists carrier u in (s, c_inf) with negation(D_M(u)).
This follows from the pigeonhole: D_M fails cofinally in the cut. The cut consists of carrier points below c_inf. For any carrier s in the cut, the pigeonhole gives u >= s in the cut with negation(truth M u D_M). Since u is a carrier point and u is in the cut (extendPoint u <= c_inf), we have s < extendPoint u <= c_inf. So exists u in (s, c_inf) with negation(D_M(u)).

But wait: the Since formula uses mu_holds, which checks for carrier points in ExtendedCarrier. A carrier s < c_inf (in ExtendedCarrier) has mu_holds(s) iff s = extendPoint(q). The pigeonhole output gives carrier-level failures (in M.carrier), but the Since quantifier is over ExtendedCarrier. Need to bridge.

Since quantifier: exists s : ExtendedCarrier M r, s < c_inf and mu_holds s and ...
The only mu-holds elements are extendPoint(q). So this reduces to: exists q : M.carrier, extendPoint q < c_inf and ... and forall u : ExtendedCarrier M r, extendPoint q < u -> u < c_inf -> mu_holds u -> D_M(u).
The universal over mu-holds u reduces to: forall q' : M.carrier, extendPoint q < extendPoint q' -> extendPoint q' < c_inf -> D_M(extendPoint q').

From the pigeonhole: for any q in the cut with x <= extendPoint q, exists u >= q in the cut with negation(truth M u D_M). This u is a carrier point, so extendPoint u is a mu-point. And extendPoint u is in (extendPoint q, c_inf] (since u >= q and u is in the cut).

So: for any carrier q as Since witness, we can find a failure point u above q. This means the universal "forall u in (q, c_inf), mu(u) -> D_M(u)" is FALSE. So Since is FALSE. K-neg = TRUE.
