## Key Architectural Decision

The plan proposed using `WorldState = Int` with position-dependent valuation. Deep analysis revealed this creates an irreconcilable conflict with the box modality:

- With `WorldState = Int`, different histories have different base states (`states t _ = c + t`)
- Box quantifies over ALL histories in Omega: `truth_at (.box psi) = forall sigma in Omega, truth_at sigma t psi`
- Different histories disagree on atom truth (different base constants give different valuations)
- No shift-closed Omega can restrict to histories with the same base state

**Resolution**: Keep `WorldState = Unit` with singleton `Omega = {tau}`. This makes box transparent (`truth_at (.box psi) iff truth_at psi`) since the only history in Omega is tau itself. The full truth correspondence (`h_truth_corr`) is taken as a hypothesis to be discharged at the call site in Phase 6.
