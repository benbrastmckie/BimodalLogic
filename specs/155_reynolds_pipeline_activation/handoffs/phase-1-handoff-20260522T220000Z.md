### Key mathematical gap

For the tau sub-case same_order_type proof, the pivot_chain_order approach requires:
- Left chain: `(x' < d iff x < c)` and `(x' = d iff x = c)`
- Right chain: from tau game orderings

The left chain is NOT directly available. It would need either:
- An instantiation of the sigma strategy (props.sigma) with specific arguments to obtain a winning condition that includes this ordering
- A direct extraction from the forward game -- but hord_fwd relates x to a_M(k) and x' to a_N(k), and a_M(n)=c but a_N(n) is NOT necessarily d

**The sigma sub-case (Case A)** has this ordering because it has `hord_sig` from the sigma strategy instantiation. **The tau sub-case (Case B)** does NOT have a sigma instantiation and needs one.

### Possible solution path

To obtain `(x' < d iff x < c)` in the tau sub-case:
1. Instantiate `props.sigma` with arbitrary selections (e.g., all d) to get a winning condition on [x',d]/[x,c]
2. Extract the ordering at positions 0 and (n+2) from this sigma winning condition
3. This gives `(x' < d iff x < c)` as needed

This is exactly what the sigma sub-case does. The tau sub-case just needs the same extraction, even though it uses the tau game for the right half of the pivot chain.
