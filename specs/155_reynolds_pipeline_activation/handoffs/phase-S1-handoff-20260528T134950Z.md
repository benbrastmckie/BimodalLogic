## The Core Problem

`nf_2var_from_interval_data` states: if two 2-variable environments (x,t) in M and (x',t') in M' agree on depth-k 1-variable NFs, orderings, interval types, and above/below types, then their depth-k 2-variable NFs are equal.

The proof CANNOT be done by induction on k (depth) alone. The inductive step at depth k+1 reduces to showing agreement on depth-k 3-variable NFs for extended environments (u,x,t) / (u',x',t'). This requires interval type data for ALL pairs including (x,u) and (u,t), which is NOT available from the hypotheses (which only provide interval data for the original pair (x,t)).

### Proof Approaches Analyzed

1. **Direct induction on k**: Base case (k=0) works. Inductive step fails because sub-interval types for new witness points cannot be derived from the hypotheses.

2. **Generalized induction (all n)**: Same blocking issue at each level -- adding a variable requires interval data for new pairs.

3. **Game infrastructure (Decomposition.lean)**: Uses ExtendedCarrier/rank_type, not nf_characteristic/nf_eval_nf. Bridging the type universes requires substantial new infrastructure.

4. **nf_agreement_monotone technique**: Requires depth-k NF agreement as hypothesis (circular -- that's what we're proving).

### Why the Game Approach Works (Mathematically)

The GHR93 proof uses a k-round EF game. Duplicator's strategy: at each round, match the new point using the interval data. After ALL k rounds, check atoms of the final (2+k)-variable environments. This works because:
- At each round, Duplicator only needs the ORIGINAL interval data to find matching points (right zone, right 1-var NF)
- The winning condition (atom agreement) is checked ONLY at depth 0, after all rounds
- Intermediate states do NOT need to satisfy the bridge lemma's invariant
