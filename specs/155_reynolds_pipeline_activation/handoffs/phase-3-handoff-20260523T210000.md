### Category A: SplitPointProps Degenerate Gap (Lines 2426, 2443)

**Root Cause**: `SplitPointProps` requires `h_pt_xc : exists p, inClosedInterval x c (extendPoint p)` and `h_pt_cy : exists p, inClosedInterval c y (extendPoint p)`. When `x = c` (resp. `c = y`) and `c` is a gap, no carrier point exists in the degenerate interval.

**Why the goals are False**: `extendPoint p = Sum.inl p` cannot equal `Sum.inr g` for any gap `g`. The interval `[x, c]` with `x = c = Sum.inr g` has width zero and contains no carrier points.

**Why the case is reachable**: `c = c_inf` (M-side infimum) is constructed from the forward game. When the M-side infimum equals a boundary and is a gap, the degenerate case is geometrically possible.

**Proposed Fix**: Make `h_pt_xc` and `h_pt_cy` disjunctive:
```lean
h_pt_xc : (exists p, inClosedInterval x c (extendPoint p)) |
           (x = c /\ IsGap c)
h_pt_cy : (exists p, inClosedInterval c y (extendPoint p)) |
           (c = y /\ IsGap c)
```

**Consumer site updates needed** (6 total):
1. `ghr93_case_I` line ~3635: `obtain <p_cy, hp_cy> := props.h_pt_cy` -- used to instantiate tau for R-side data. In degenerate gap case, tau is vacuous (no carrier points), so R-side data must be derived directly from gap properties. Requires case split.
2. `ghr93_case_I` line ~4038: `obtain <p_xc, hp_xc> := props.h_pt_xc` -- symmetric to above for L-side.
3. `ghr93_case_II` line ~4537: `obtain <p_cy, hp_cy> := props.h_pt_cy` -- used before IsPoint c is derived. Degenerate case (c = y gap) is unreachable in Case II because: c = y gap => d = y' gap => a_bwd(n) = d is a gap => contradicts h_point (Case II requires a_bwd(n) is a carrier point).
4. `ghr93_case_II` line ~5072: Same as (3), unreachable by same argument.
5. `ghr93_case_II` line ~5091: `obtain <p_xc, hp_xc> := props.h_pt_xc` -- after IsPoint c is established (line ~5090). Degenerate case (x = c gap) is unreachable because c is already known to be a carrier point.
6. `ghr93_case_II` line ~5425: Same as (5).

**Key finding**: Consumer sites in Case II are trivially fixable (degenerate gap contradicts IsPoint c). Consumer sites in Case I are harder: when a sub-interval is degenerate-gap, the sub-game can't be instantiated with a carrier point, so auxiliary data must be derived differently.

**Effort**: ~3-5 hours for the full refactor.

### Category B: Gap Infimum Wiring (Lines 2013, 2104)

**Root Cause**: Case 3 of the infimum construction (no carrier-point GLB) needs to use `infimum_gap` + `infimum_gap_r_definable` to construct `d` as an r-definable gap.

**Preconditions for `infimum_gap`**:
- `h_ne` (have it)
- `h_pt_below` (have it)
- `h_above : exists q (s : S_C), extendPoint q > s.val` -- need to derive
- `h_not_point_glb` (same as negated `h_has_glb`, have it)

**Deriving `h_above`**: Take any `s_0 in S_C`:
- If `s_0` is a carrier point `Sum.inl p_0`, apply `h_has_pt_min` to get `exists s in S_C, s < extendPoint p_0`. Set `q = p_0`.
- If `s_0` is a gap `Sum.inr g_0`, use `g_0.val.proper` (cut != Set.univ) to get `q not in g_0.val.cut`, meaning `Sum.inr g_0 <= extendPoint q`, so `extendPoint q > s_0`.

**Preconditions for `infimum_gap_r_definable`** (harder):
- `hx'_bound`: exists carrier-point lb of S_C at or above x'. When x' is a carrier point, trivial (x' itself). When x' is a gap, requires finding a lb above x'.
- `h_above_gap_below_y'`: exists carrier point NOT in inf_carrier_cut, below y', above x'. Derivable from `h_above` after showing the carrier point is in the right range.

**Key difficulty with `hx'_bound`**: When x' is a gap, all carrier-point lbs from `h_pt_below` may be below x'. Need to show either: (a) some lb is above x' (using the ascending chain from negated `h_has_glb`), or (b) x' itself is the GLB (meaning d = x').

**Proposed approach**: Split the Case 3 into sub-cases:
- Sub-case 3a: exists carrier-point lb p with x' <= extendPoint p. Use infimum_gap + infimum_gap_r_definable.
- Sub-case 3b: all carrier-point lbs are below x'. Then inf_carrier_cut subset x'.cut (if x' is a gap), so the infimum gap gamma has gamma.cut subset x'.cut, meaning gamma <= x'. Since x' is also a lb of S_C (S_C subset [x', y']), x' is the GLB. Set d = x'.

**Effort**: ~4-8 hours.
