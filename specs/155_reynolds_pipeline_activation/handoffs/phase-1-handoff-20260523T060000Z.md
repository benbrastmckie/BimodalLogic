### Key Structural Insight

The root cause is a mismatch between GHR93's proof structure and our formalization:

**GHR93**: c = inf(S_C^M) and d = inf(S_C^N). Both are infima of their respective continuation sets. The K^-(not-D) argument uses BOTH infimum properties to show K^-(not-D)(c) = TRUE (D fails cofinally below c in M) and K^-(not-D)(d) = TRUE (D fails cofinally below d in N). Then the game at rank r+2 gives K^-(not-D)(c) <-> K^-(not-D)(game response), constraining the response to match d's position.

**Our code**: c is constructed from a 1-round game play (not as inf(S_C^M)). It has rank-r formula agreement with d but NO infimum properties. We can't determine K^-(not-D)(c) because we don't know if D fails cofinally below c in M.
