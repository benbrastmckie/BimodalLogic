### The one disagreement, and why the tool is right

`Semantics.truth_at` classifies as `prop_valued_definition`: after telescoping its binders the
result type is `Prop`. It *defines* a predicate. The plan's own three-branch rule then mandates
**UpperCamelCase** ("result type is `Prop`, i.e. it defines a predicate -> UpperCamelCase
(Mathlib: `Function.Injective`, `IsCompact`)"), giving `TruthAt`.

The plan's worked example `truth_at -> truthAt` predates that rule — it comes from the research
mechanism experiment, which renamed `truth_at` purely to prove the rewriter worked and was
never a casing judgement. **The rule wins; the worked example is stale.** This is flagged here
rather than silently resolved because it changes the most-referenced declaration in the
migration.

**This is the single most consequential item for the reviewer.**
