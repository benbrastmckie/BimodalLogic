### Research Integration

Key findings from `reports/01_machinereadable-jsonl-appendix.md` incorporated:
- **Implicit-index extraction** (fidelity core): because `Axiom : Formula → Type` is indexed by
  the axiom's schema formula, `mkAxiomEntry {φ : Formula} ... (ax : Axiom φ)` recovers the schema
  from the type index and the frame class from `Axiom.minFrameClass` — a wrong entry is a Lean
  type error, never silent drift. Same trick serializes derived-operator unfoldings via the real
  `def`s (kernel-computed, never transcribed).
- **Reuse targets**: `Formula.toJson` / `prettyPrint` / `escapeJsonString` (DataExport.lean:104),
  metadata-envelope precedent (DatasetExporter.lean), JSONL streaming + `--output` CLI precedent
  (DatasetExport.lean), `allAxiomNames` 42-name list + `checkCoverage` idiom
  (BenchmarkAnchors.lean:297), 11 existing `lean_exe` stanzas in `lakefile.lean` with
  `srcDir := "Theories"` and `supportInterpreter := true`.
- **Artifact location constraint**: `.gitignore` excludes `data/*.jsonl` and `build/`; the only
  committed generated home is `Theories/Bimodal/typst/generated/` (verified: `status.typ` is
  tracked there).
- **Stamping**: git stamps injected by wrapper script via `--stamp-commit`/`--stamp-date` CLI
  args (research option (a)) — the Lean exe never shells out to git.
- **Book wiring**: appendix chapter included in `BimodalReference.typ` between
  `chapters/06-notes.typ` and the References heading; pointer subsection in
  `chapters/p4-dataset-pipeline.typ` (task-319 re-anchor — the former AI-intro section no longer
  exists).
- **No proof obligations**: all Lean additions are computable defs/structures + `IO` main; zero
  sorry risk (hence Lean Intent: false).
