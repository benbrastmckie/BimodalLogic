## Behaviour Phase 5 depends on

- **Dependency order.** `sig% Sig.and φ ψ` needs `T.neg` in the environment. If it is missing the error reads "`FormalSystem.Syntax.Sig.neg` survives in the generated body … Define `T.neg` before this definition."
- **Agreement check.** `Sig.op` is replaced by `T.op` only when `isDefEq` holds between the two applications. A `T.op` with another body raises "`T.op` exists but does not agree with `Sig.op`".
- **Arity.** The replacement takes the last `n` arguments of the `Sig.op` application, `n` being the number of binders of `T.op`'s type. A per-language definition with extra leading arguments would not fit.
- **Head.** A term whose head constant is not in `FormalSystem.Syntax.Sig` is rejected.
- **Projections.** A `Has*` projection application is reduced by `whnf` at instance transparency. With an instance of the form `⟨T.ctor⟩` that yields the constructor application. An instance whose field is a reducible definition would be unfolded further.
