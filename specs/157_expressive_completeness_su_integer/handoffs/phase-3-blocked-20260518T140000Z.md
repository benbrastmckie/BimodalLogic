## Root Cause

The temporal closure axioms (`all_past_separable`, `all_future_separable`,
`snce_separable`, `untl_separable`) cannot be proved by simple induction.

**Why structural induction fails**: The `all_past`, `all_future`, `snce`, and
`untl` cases of structural induction need temporal closure. E.g., proving
`is_separable (.all_past phi)` from `is_separable phi` requires showing that
the separated equivalent of `H(phi)` exists, which is the very thing temporal
closure asserts.

**Why junction_depth induction fails**: `junction_depth(.all_past phi) = junction_depth(phi)`,
so junction_depth doesn't decrease through `all_past`.

**Why (junction_depth, formula_size) lex induction fails**: The separated equivalent
psi of phi can be LARGER than phi (the Cases 1-8 formulas expand the formula).
So while `formula_size(phi) < formula_size(.all_past phi)` decreases, applying
the IH to `.all_past psi` requires `formula_size(.all_past psi) < formula_size(.all_past phi)`,
which is not guaranteed because `formula_size(psi)` may be >> `formula_size(phi)`.

## What Is Needed

The GHR94 approach uses "constituent substitution":
1. Given a separated formula `E'` (boolean combination of atoms, U-terms, S-terms)
2. Replace each atom `p_i` that was abstracted from an S-term with its original S-term
3. Each resulting "past constituent" has strictly lower junction_depth
4. Apply IH to each constituent individually

This requires:
- `SepDecomp` structure tracking the boolean/U-term/S-term decomposition
- `subst_past_constituents` function replacing atoms in S-terms
- Proof that each constituent has lower junction_depth after substitution
- Composition of separated forms across the boolean structure
