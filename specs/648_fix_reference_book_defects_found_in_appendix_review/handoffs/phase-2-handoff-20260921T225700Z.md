## Partial-file commit technique used

`typst/chapters/ax-lean-appendix.typ` carries both my title-heading edit AND an unrelated,
pre-existing foreign uncommitted diff (editorial TODO comments, not task 648's to touch — see
Phase 1's handoff). To commit only my hunk: extracted just that hunk from `git diff` into a
patch file, staged it with `git apply --cached <patch>`, then committed with a bare
`git commit -m ...` (no pathspec, so it commits exactly the index as staged) rather than
`.claude/scripts/git-commit-scoped.sh` (which re-`git add`s the whole file by path, sweeping in
the foreign hunks). Verified before and after via `git status --porcelain` /
`git diff --staged --stat` that nothing else was staged at the time. This same technique will be
needed again for any future phase touching this file's title/numbering block while the foreign
diff remains uncommitted.
