## Overview

`scripts/check-module-invariants.sh` carries an `INV` check that re-runs its own
`--emit-inventory --check` sub-mode and reports any `<!-- BEGIN GENERATED: inventory ... -->`
block whose regenerated bytes differ from the committed ones. Three such blocks are stale because
the last `FormalSystem/` commit (`4155ee185`, a MintBound/README module re-measure) postdates the
last commit touching the READMEs that carry `dir=FormalSystem`-rooted blocks (`ec8483a01`). The
remedy is the script's own writer mode: run `--emit-inventory`, read the diff to confirm only
machine-owned numeric cells moved, commit the three README files, and confirm the `FAIL  INV`
group is gone from a fresh `check-module-invariants.sh` run. No Lean source, no `Tests/`, and no
script changes.
