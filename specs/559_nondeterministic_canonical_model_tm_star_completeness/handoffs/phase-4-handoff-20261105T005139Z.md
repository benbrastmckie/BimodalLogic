## Note on `Fresh`

`Fresh q .bot = True` is a match arm, not a `def X := True` body: `⊥` contains no atom, so `True`
is the correct value and not a vacuous placeholder. The three `example`s pin non-vacuity
mechanically (it rejects `atom q`, accepts `atom p` for `p ≠ q`, and rejects `⊡(atom q)`).
