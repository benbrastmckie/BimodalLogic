### The measure checks out against GHR's worked example

With `jdU`/`jdS` as Phase 24's first bullet specifies them, GHR's
`S(a ∧ U(A, S(C, D)), S(S(C, D), E))` — translated to this subtree's guard-first order as
`snce (snce E (snce D C)) (and a (untl (snce D C) A))` — computes to `jdU = 2`, `jdS = 3`,
`junctionDepth = 3`, matching the source's stated 3; the second appearance of `C`, inside
`S(S(C,D), E)` = `snce E (snce D C)`, sits at `jdS = 1`, matching the source's stated 1. The
"skip" branch is needed: without it `jdU` of the `and`-conjunct would not reach the `U` under the
outer `S`. Land the example as the bullet directs, but the equations as written are correct.

This was **checked mechanically, not by hand arithmetic**: a self-contained snippet (a five-
constructor clone of `USForm`, the two equations verbatim, `#eval` on the translated example) ran
green under `lean_run_code` and printed `(jdU, jdS, junctionDepth)` as `(0,1,1)` for `S(C,D)`,
`(2,1,2)` for `U(A,S(C,D))`, `(2,1,2)` for the `and`-conjunct, `(0,1,1)` for `S(S(C,D),E)` and
`(2,3,3)` for the whole formula. Two further probes pin the `NoSnceUnderUntl → junctionDepth ≤ 2`
claim as tight rather than merely true: a `U` beneath an `S` (`NoSnceUnderUntl` holds) evaluates
to `2`, and an `S` beneath a `U` beneath an `S` (`NoSnceUnderUntl` fails) evaluates to `3`. The
snippet also confirms that the two equations elaborate as a `mutual` structural recursion with
**no** `decreasing_by` and no termination hint, so Phase 24's first bullet carries no hidden
well-founded-recursion risk.

### Part (c), and why the duality reduction is load-bearing rather than cosmetic

Write `n = junctionDepth φ`, `L` for the abstracted maximal `snce`s, `mU = max_{E ∈ L} jdU E` and
`mS = max_{E ∈ L} jdS E`, and `S = sep7 φ'` (separated), `S' = substLeaf (unabstrFn j L) S`.

Four substitution bounds, each a clean induction on `IsUOnly`/`IsSOnly` (the `untl` case of `jdS`
and the `snce` case of `jdU` contribute no `1 +`, which is what makes them go through):

- `jdS (substLeaf h ψ) ≤ e` when `IsUOnly ψ` and `∀ i, jdS (h i) ≤ e`;
- `jdU (substLeaf h ψ) ≤ max d (1 + e)` when `IsUOnly ψ`, `∀ i, jdU (h i) ≤ d`, `∀ i, jdS (h i) ≤ e`;
- and the two mirrors under `IsSOnly`.

Running them over `S`'s three node kinds — Boolean, pure-`U` `untl` (both arguments `IsUOnly`),
pure-`S` `snce` (both arguments `IsSOnly`) — gives

    jdU S' ≤ max mU (1 + mS),   jdS S' ≤ max mS (1 + mU),
    junctionDepth S' ≤ 1 + max mU mS.

Now the two bounds on `L`. For `E ∈ L` inside the maximal `untl` `W ∈ uTypes φ`:
`jdU W ≥ 1 + jdS ψ ≥ 1 + jdS E`, so `mS ≤ jdU φ - 1`; and since `E` is `snce`-headed,
`jdS E ≥ 1 + jdU E`, so `mU ≤ mS - 1`.

**For a general `φ` this is not enough.** `jdU φ ≤ n` gives only `mS ≤ n - 1` and hence
`junctionDepth S' ≤ n` — no strict drop, and this is exactly where a dispatch that skipped the
sizing would stall. The missing step is GHR's own: *"because of the dual nature of the results so
far we need only demonstrate the syntactic separation of a wff of the form `S(D₁, D₂)`"*. For an
`snce`-headed `φ`, `jdS φ ≥ 1 + jdU φ`, so `jdU φ ≤ n - 1`, so **`mS ≤ n - 2` and
`mU ≤ n - 3`**, and therefore

    junctionDepth S' ≤ max (1 + mS) (1 + mU) ≤ n - 1.

Strict. The general condition the step needs is `jdU φ < jdS φ`, which an `snce`-headed formula
satisfies automatically and the dual step's mirror condition `jdS φ < jdU φ` an `untl`-headed one
does. **Neither holds when `jdU φ = jdS φ`**, which is reachable at `n ≥ 2` (take `and A B` with
`jdU A = jdS B = 2` and `jdS A = jdU B = 1`), so the step cannot be applied to an arbitrary `φ`:
it must be applied at **maximal temporal nodes**, where the head's own kind forces the inequality.
This upgrades Phase 24's duality bullet from a convenience that "lets the recursion treat only the
`snce`-headed case" to a precondition of part (c) itself.

### What that implies for `sep8Body`'s shape

Phase 24's recursion bullet describes `sep8Body` as "returning `φ` unchanged at junction depth at
most one" — which is sound here, unlike Phase 23's corresponding sentence, because
`junctionDepth φ ≤ 1` really does imply `IsSeparated φ`. But the guard cannot sit at the top of an
arbitrary `φ`: the step below it needs a temporal head. The shape the sizing points to is a plain
structural recursion over the Boolean skeleton with the step at each maximal temporal node:

    sep8Body k (.leaf i)    = .leaf i
    sep8Body k .bot         = .bot
    sep8Body k (.imp a b)   = .imp (sep8Body k a) (sep8Body k b)
    sep8Body k (.untl ψ φ)  = if junctionDepth (.untl ψ φ) ≤ 1 then .untl ψ φ
                              else k (sep8StepDual (.untl ψ φ))
    sep8Body k (.snce ψ φ)  = if junctionDepth (.snce ψ φ) ≤ 1 then .snce ψ φ
                              else k (sep8Step (.snce ψ φ))

with `sep8Step φ = substLeaf (unabstrFn φ.freshLeaf (innerSTypes φ)) (sep7 (mapU (abstrSnceArgs
φ.freshLeaf (innerSTypes φ)) φ))` and `sep8StepDual φ = (sep8Step φ.swap).swap`. This needs **no**
new mapping operator — the Boolean descent is the recursion's own `imp` case, so neither `mapU`
nor `mapS` is asked to do something it does not do, and the blocking check on redefinitions stays
clean. Note the two landed operators are not symmetric and this matters: `mapS` stops at `untl`
without descending, so its targets are the Boolean-level `snce` nodes, whereas `mapU` descends
through `snce`, so its targets are `uTypes`. `abstrSnceArgs` wants the second behaviour on the
outside and the first on the inside, which is exactly the `mapU`-at-a-`mapS` composition Phase
24's abstraction bullet already specifies.
