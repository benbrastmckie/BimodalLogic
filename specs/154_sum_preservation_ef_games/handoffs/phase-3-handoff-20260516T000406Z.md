## Mathematical Analysis Summary

The core mathematical issue is that in a linear order, knowing two elements' individual "types" (1-variable normal forms) does not determine their order relationship. Counterexample: in Z with no predicates, all elements have the same depth-0 1-var NF, but their pairwise orders vary.

The fix: witnesses must be selected to preserve order with ALL existing environment elements. This is possible because the component's (k+1)-equivalence provides enough quantifier depth to match multi-variable NFs that include order atoms. The number of same-component environment elements never exceeds k (since n + k' = k_original throughout the recursion), and the component has k+1 levels of equivalence.
