## Root Cause Analysis

The 6 Cluster 1 errors (lines 547-550, 628-631) stem from `.1` (Sigma projection) failing on `Fin.cons (show (orderedSum sig I ms).carrier from <j, c>) env_M p`. Three interacting issues form a trilemma:

1. **`.1` opacity**: `show T from x` prevents `.1` projection. Using `@Fin.cons n (fun _ => T) <j,c> env_M` fixes this.

2. **eM/eN dite type mismatch**: With `@Fin.cons` env, the `eM`/`eN` fields use `if h : j' = j then h subst Fin.cons c (cd.eM j) else cd.eM j'`. The `else` branch has type `Fin (cd.sz j') -> (ms j').carrier` but expected type is `Fin (if j' = j then cd.sz j + 1 else cd.sz j') -> (ms j').carrier`. Lean's `dite` doesn't reduce the `if` in the TYPE. Adding `Fin.cast (if_neg h)` in else branch fixes this.

3. **eN then-branch elaboration order**: After fixing eM (which works), eN's then-branch fails because after `h subst`, the expected type has `if j' = j'` (which Lean doesn't reduce). eM succeeds by coincidence of elaboration order (it's the first field). Tactic-mode workarounds (`by_cases/subst/exact`) create `Decidable.casesOn` terms that block downstream `agree`/`consistent` proofs.

## Recommended Phase 3 Approach

Define a helper function that constructs cd' via explicit arguments instead of structure literal syntax:

```lean
private noncomputable def extend_CompData (sig : MonadicSignature) {I : Type} [LinearOrder I]
    {ms ms' : I -> OrderedMonadicStructure sig} {budget n : Nat}
    {env_M : Fin n -> (orderedSum sig I ms).carrier}
    {env_N : Fin n -> (orderedSum sig I ms').carrier}
    {h_idx : forall p : Fin n, (env_M p).1 = (env_N p).1}
    (cd : CompData sig I ms ms' budget env_M env_N h_idx)
    (j : I) (c : (ms j).carrier) (c' : (ms' j).carrier)
    (h_ext_agree : ...) (hK_eq2 : ...) :
    CompData sig I ms ms' budget
      (Fin.cons (show (orderedSum sig I ms).carrier from <j, c>) env_M)
      (Fin.cons (show (orderedSum sig I ms').carrier from <j, c'>) env_N)
      (Fin.cases rfl (fun k => h_idx k)) := by
  -- Construct in full tactic mode with explicit subst at each field
  exact { sz := ..., eM := ..., eN := ..., agree := ..., bound := ..., consistent := ... }
```

By extracting this to a standalone definition, Lean has more flexibility in elaboration and the body can use full tactic mode without contaminating the build_bicompat proof context.
