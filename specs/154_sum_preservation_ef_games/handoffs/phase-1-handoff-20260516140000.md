   successfully resolves the type mismatch for eM and eN fields. This approach rewrites the if
   BEFORE providing the term.

3. **agree field blocked**: After `split_ifs with h`, the isTrue case works via `subst h` BUT
   `subst h : j' = j` eliminates `j` (keeps `j'`), leaving `if j' = j' then ...` which doesn't
   reduce. Using `rcases` with `⟨rfl⟩` has the same issue. The isFalse case cannot reduce
   `if j' = j then ...` in the goal because `rw [if_neg h]` fails with "motive is not type correct"
   due to dependent types.
   
   `simp_rw`, `simp only [h]`, `simp only [if_neg h]` all fail to make progress.

4. **bound field**: Works with `show ... ; rcases ... ; rw [if_neg h]; rw [if_pos rfl]; omega`.

5. **`decEq` doesn't exist**: The plan's `match decEq j' j` approach fails because `decEq` is
   not a generic Lean 4 function. `match inferInstance : Decidable (j' = j)` has sort/universe
   issues ("Not supported on type universe" or "Type mismatch: Decidable ... of sort Type but
   expected Type of sort Type 1").
