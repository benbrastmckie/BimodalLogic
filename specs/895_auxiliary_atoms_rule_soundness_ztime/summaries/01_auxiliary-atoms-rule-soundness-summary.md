## Decisions

- **`hexh` is retained in the headline signatures and is not consumed by the proof.** The
  antecedent's step clause is an implication, so a point at which no `aᵢ` holds places no demand
  on the machine and `aaIdx`'s `0` fallback is never read. Exhaustiveness is what makes the rule
  *useful* — it pins the machine's run down to a single run, which is how Reynolds uses it — not
  what makes it sound, so the rule proved is in that one respect stronger than the rule stated.
  The binder is kept because it is the Challenge-pinned published signature and because dropping
  it would silently change the rule's shape relative to the source. Suppressed by the
  repository's own established pattern (`Semantics.coneF_surjective`,
  `TwoWayBounded.plus_invariance_of_isZTime`): a scoped
  `set_option linter.unusedVariables false in`, `@[nolint unusedArguments]`, and a paired entry
  in `scripts/nolint-attribute-allowlist.txt`, with the reason written at the site. Deletion
  trial measured with `lean_minimal_hypotheses`: no error arises inside the proof, the only
  breakage being the positional application at `aa_sound_ztime`'s call site.
- **`aaIdx` carries no `[F.IsRegular]` binder.** It reads only world states and histories.
  Regularity is needed at `aaIdx_of_occurring` and `aaIdx_spec`, where `PlusValidInt`'s own
  `[F.IsRegular]` binder has to be discharged to instantiate the partition hypotheses. An
  initially-carried binder there was a genuine C16 `unusedArguments` finding and was dropped
  rather than nolinted — unlike `hexh`, it had no contract to justify it.
- **The two partition hypotheses are consumed one per lemma**, not both by `aaIdx_spec`:
  `aaIdx_of_occurring` consumes exhaustiveness, `aaIdx_spec` consumes pairwise inconsistency
  together with state-locality (through `plusTruthAt_stateLocal_state_only`). `aaIdx_spec`'s own
  witness hypothesis already reaches the `dite`'s real branch, so an exhaustiveness binder there
  would be unused and rejected under `--wfail`.
- **The three `plusTruthAt_aaAnte_*` unpacking lemmas conclude at
  `M.valuation (σ.state s) (qa j)`** rather than `PlusTruthAt M σ s (PlusFormula.atom (qa j))` —
  definitionally the same statement (`PlusTruth.atom_iff` is `Iff.rfl`) and the shape every
  consumer wants. These are internal machinery, deliberately not Challenge-pinned.
- **`aaIdx`'s `dite` needs an explicit `haveI : Decidable … := Classical.dec _`**; the instance
  does not synthesize otherwise.
- Every decision recorded in the plan's own `## Decisions` section was honoured without change:
  statement level `PlusValidInt`, the concrete cone API rather than `exists_coneUnravelling`,
  `ℕ`-indexed bounded families, semantic-validity partition conditions, the double-negated
  `bigAnd` for exhaustiveness, the `top`-guarded exclusivity diagonal, `NamingRules.Fresh`
  reused, one new module plus a prose-only `NamingRules.lean` change, the mirror stated rather
  than expanded, and the three infrastructure lemmas kept local.
