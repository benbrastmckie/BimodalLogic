## The ruling

**Reconciled, not divergent.** Both source sections were read in full during this dispatch
(not only the research report's account of them). Source A (706 Q4, "What follows for a
certificate class") places NON-VALIDITY in NEXPTIME and VALIDITY in co-NEXPTIME, concluding
`2EXPTIME ⊆ co-NEXPTIME`. Source B (703 round-2 section 1.6, "What remains unknown") speaks of
a singly exponential certificate putting "a 2EXPTIME-hard problem in NEXPTIME"; the problem it
is certifying is the satisfiability side, i.e. non-validity. The two containments
(`2EXPTIME ⊆ NEXPTIME` and `2EXPTIME ⊆ co-NEXPTIME`) are equivalent because 2EXPTIME is a
deterministic class closed under complement, so the two sources name opposite sides of one
statement. Only source B's phrasing omits which problem it is placing. The canonical wording
now in 713's description names both sides and requires any record repeating it to say which
problem it places (NON-VALIDITY with NEXPTIME; VALIDITY with co-NEXPTIME).
