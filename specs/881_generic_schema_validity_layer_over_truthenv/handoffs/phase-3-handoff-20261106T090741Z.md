- **Tactic-shape finding worth carrying forward**: `simp only [ImpClause.imp_clause, allFuture_iff]`
  does NOT work here, unlike its `StarTruth` counterpart. `TruthClauses.allFuture`/`allPast` are
  `abbrev`s (reducible), so `imp_clause` matches *through* them and consumes the term before
  `allFuture_iff` can fire — the symptom is "This simp argument is unused" on `allFuture_iff` plus
  an application type mismatch. Use an ordered `rw [ImpClause.imp_clause]; intro h;
  rw [allFuture_iff] at h; …` instead. Every later phase touching `allFuture`/`allPast`/`someFuture`
  /`somePast` under an implication needs this shape.
