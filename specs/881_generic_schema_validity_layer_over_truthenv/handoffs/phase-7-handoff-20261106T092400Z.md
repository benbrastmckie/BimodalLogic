  (`simp only [StarTruthAt, StarFormula.and, StarFormula.kPlus, …]`). `kPlus_iff`/`kMinus_iff`
  give that shape directly, so the generic proof is markedly shorter than either.
- **Third ordering trap recorded**: `kPlus ψ` is `neg (untl (neg ψ) top)`, so `neg_iff` matches a
  `kPlus` term. `kPlus_iff`/`kMinus_iff` are always applied *before* `neg_iff`, never in the same
  `simp only`.
