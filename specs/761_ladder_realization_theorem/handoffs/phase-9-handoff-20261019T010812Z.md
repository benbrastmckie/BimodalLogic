## THE EXCLUSION — read this before Phase 11

Phase 9's `Dmax` task justified maximality by "the union of certified sets is certified, so the
maximum exists". **That clause is false for this certificate and is NOT proved.** `certStabK` and
`certBoxK` are BICONDITIONALS between a letter's bit and a fibre of the candidate set, so a
member whose `stab`/`box` bit is set in a small certified set has that bit falsified as soon as
the union adds a member missing the argument. Only the four monotone conditions survive a union,
and those four are proved OF `Dmax`.

What this means downstream: `Dmax`'s own certification must be reached by Finding 3's route — the
realizable set is certified GIVEN constancy of `cellAt` on `K`-classes — which is what Phases
11-13 are for. It must NOT be reached by a union argument, and no later phase may assume
`certAdmK … (Dmax …)`; the module states in its own "What this module does NOT hold" section that
nothing here claims it.
