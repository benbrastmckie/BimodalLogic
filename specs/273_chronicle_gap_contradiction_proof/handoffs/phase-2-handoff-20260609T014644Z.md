## Root Cause

The NF-based proof technique processes variables one at a time via zone matching. Each zone match preserves orderings relative to the interval ENDPOINTS but loses information about orderings relative to previously matched INNER points. The GHR93 paper avoids this via multi-point Duplicator strategy (Proposition 7) using decomposition formulas. The formalized codebase uses NFs rather than decomposition formulas, and the NF-to-game bridge does not exist.
