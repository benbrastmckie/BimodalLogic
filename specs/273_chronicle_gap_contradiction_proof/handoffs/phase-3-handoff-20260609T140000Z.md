## Why Proposition 7 Is Needed

The bridge lemma says: given 2-point structural data agreement (1-var NFs, ordering, interval types), the 2-var depth-k NFs agree. The proof needs existential transfer at all depths j < k for 3-variable extensions.

For j=0: zone matching + atom agreement suffices (already proved, sorry-free).
For j >= 1: zone matching gives a matched triple (u,x,t)/(u',x',t') with correct 1-var NFs and orderings. But the interval types between newly matched pairs (e.g., between u and x vs u' and x') are NOT guaranteed to agree.

The fundamental issue: the game at n=0 rounds, rank k/2 gives independent point matchings that are not jointly consistent for sub-interval decomposition. Proposition 7 iterates the game, using `ghr93_strategy_compose` at each step to ensure sub-interval types are correctly split.

## Eight Approaches Considered and Rejected

1. **Direct induction on j**: Fails because interval types between matched pairs don't agree.
2. **Game at (0, k/2) for multi-point matching**: n=0 game gives one independent match per challenge, not consistent multi-point matching.
3. **Bypass bridge lemma**: Formula `nf_exist_sf_guarded` doesn't encode quantifier part of sub_nf, so backward direction requires bridge lemma.
4. **Classical argument from forward direction**: The formula for different sub_nf (same atoms) is identical, so it can't distinguish them.
5. **Induction on k with IH at all variable counts**: Needs interval type agreement at (n+1)-point level, which again needs Proposition 7.
6. **Higher rank decomposition agreement**: rank_type at k requires depth-2k NF agreement, but hypotheses only give depth-k.
7. **Reference model + transfer**: Uses `nf_2var_transfer` which depends on `nf_2var_from_interval_data` (sorry'd).
8. **Different formula construction**: Could encode more structural data, but would require substantial refactoring of the formula construction pipeline.

**What to prove**: From decomposition_agreement at all sub-intervals of [x,y], derive `ghr93_duplicator_wins M M' atomMap n r x y x' y'` for sufficiently large n.

**Key ingredients** (all sorry-free):

- `ghr93_game_implies_decomposition`: Game wins -> decomposition agreement (Decomposition.lean:117)

- `discrete_ghr93_theorem6`: Forward-to-backward game inversion with h_r1_univ (DiscreteGameTransfer.lean:663)

**Proof structure** (GHR93 pp.115-116):
1. Induction on n (number of rounds)
2. Base case n=0: trivial
3. Step n->n+1: Spoiler picks alpha. Use decomposition to find a split point d. Apply `ghr93_strategy_compose` with:
   - Left strategy: game on [x,d] (from IH)
   - Right strategy: game on [d,y] (from IH)
   - Split properties from `obtain_split_point_props`
4. The IH at n requires forward games at (1+3n, r) which are inverted to backward games at (n, r) via `discrete_ghr93_theorem6` with h_r1_univ.

**The h_r1_univ threading**: The caller (Phase 4) provides h_r1_univ from the decomposition formula agreement. For discrete orders, decomposition agreement at rank r gives formula agreement at all sub-intervals, which can be lifted to rank r+2 using the fact that all elements are carrier points.
