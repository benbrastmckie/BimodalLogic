## Key Findings

### Why d-consistency (sorry sites 1-2) cannot be proved independently

The d-consistency goal asks: for ANY selection ending with c, the forward game's response at c's position equals d. This requires:
- Constructing formula C that uniquely characterizes d in [x',y']
- This is the full GHR93 Claim 1 argument (1629 lines in Claim1.lean)
- The existing `d_consistency_left` theorem handles boundary cases (x'=d or d=y') and delegates the interior case to `h_interior_d` -- which `obtain_split_point_props` constructs

### Why rank-UP conversion fails

Even for discrete orders, going from game at rank r to rank r+2 fails:
- Game at rank r gives formula agreement for depth <= r
- Game at rank r+2 needs formula agreement for depth <= r+2
- Formula truth at carrier points is rank-independent (stavi_truth_mu_at_point)
- BUT: the game only tests formulas up to rank r, so formulas at depth r+1 and r+2 are untested
- Two carrier points can agree on all rank-r formulas but disagree on rank-(r+1) formulas

### Why the current architecture is flawed

`discrete_backward_extend` assumes a FIXED pivot (C, D) and handles ALL Spoiler selections. But:
- If all n+1 selections are on one side of D (e.g., all >= D), the corresponding sub-strategy handles only n elements
- GHR93 resolves this by choosing D = infimum(continuation_set), which DEPENDS on Spoiler's last selection a_bwd(n)
- The properties `D <= a_bwd(n)` (ensuring R is nonempty in Case I) comes from this selection-dependent pivot choice
