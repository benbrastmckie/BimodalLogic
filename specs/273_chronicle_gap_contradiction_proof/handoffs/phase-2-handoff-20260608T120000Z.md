`G_{n+1; r}(...)`. This requires:

1. **Unfold backward game**: `intro a' ha'` to get Spoiler's n+1 selections
2. **Handle first n selections**: Apply h_bwd_n with first n elements (lifted to rank r+4)
3. **Handle (n+1)-th selection**: Use h_fwd_1 Round 2 to find matching point
4. **Handle challenge point**: Use h_bwd_n Round 2 for M-challenge
5. **Prove winning condition**: Order, gap/point, and formula agreement

The main mathematical obstacle: the winning condition requires ALL n+4 indices to
have consistent ordering and rank-r formula agreement. The first n matching points
come from h_bwd_n (rank r+4 agreement), the (n+1)-th from h_fwd_1 (rank R agreement),
and orderings must be cross-consistent between the two groups.
