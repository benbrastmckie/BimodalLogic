## Root Cause Analysis (Definitive)

The sorry chain traces back to `nf_2var_existential_transfer` (lines 2353/2435) which needs the 4-variable existential transfer at depth j' for a 3-point configuration. This transfer requires proving n-variable NF agreement when adding a new variable via zone matching.

Zone matching on the original pair (x,t) finds w' with the same 1-var NF and orderings relative to x,t. But for the n-var atoms to agree, we need orderings between w' and ALL other matched points. When w and another matched point u are in the SAME zone relative to (x,t), their relative ordering is NOT determined by zone matching alone.

This is the "sub-interval type matching problem" that has blocked ALL prior plan versions (v3-v8). The GHR93 game approach resolves it by absorbing variable counts into game rounds, but implementing the game inductive step (Theorem 6 Claims 1-2) has proven difficult.
