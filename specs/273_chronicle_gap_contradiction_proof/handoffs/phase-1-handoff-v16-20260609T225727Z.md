## Key Discovery

The sorry at line 2405 asks for 4-var existential transfer at depth j' for the 3-point context (u,x,t)/(u',x',t'):

```
(∃ w', nf_eval_nf M' j' 4 (w'::u'::x'::t') sub_nf) ↔ 
(∃ w, nf_eval_nf M j' 4 (w::u::x::t) sub_nf)
```

This requires placing w' in the CORRECT GAP among {u', x', t'} with the correct 1-var NF. When w is in the interval (x, u) (i.e., x < w < u < t), we need w' in (x', u'). But the hypothesis `interval_nf_types M k x t = interval_nf_types M' k x' t'` only guarantees types in the FULL interval (x,t), not the sub-interval (x,u).

## Counterexample (1-var interval types insufficient)

M: x < A_point < B_point(=u) < C_point < t
M': x' < C_point' < B_point'(=u') < A_point' < t'

Both have interval_nf_types = {A, B, C}. But:
- interval_nf_types M k x u = {A}
- interval_nf_types M' k x' u' = {C}

Sub-interval types differ, so the 4-var atom transfer at depth 0 fails when w is of type A in (x, u): there is no type-A point in (x', u').

NOTE: At depth k >= 2, the depth-2 1-var NF of x constrains the arrangement (because it encodes which 2-var NFs are realized above x), potentially excluding this counterexample. This is the basis for approach (2): the sub-interval types at depth k-1 ARE constrained by the depth-k endpoint NFs, even though the depth-k sub-interval types are not.

## Recommended Resolution: Depth-Decreasing Game (Approach 2)

Key insight: the depth-k 1-var NF of u encodes "which 2-var NFs (v, u) at depth k-1 are realized." For v < u, this records which depth-(k-1) 1-var NFs exist among points below u. Combined with the depth-k 1-var NF of x (which records types above x), the depth-(k-1) types in (x, u) are determined BY INTERSECTION:

- types_below_u = {sigma | exists v < u with depth-(k-1) NF sigma}
- types_above_x = {sigma | exists v > x with depth-(k-1) NF sigma}
- types_in_(x,u) SUBSET types_below_u INTERSECT types_above_x

HOWEVER: the intersection is a SUPERSET of types_in_(x,u), not exact equality. Points below u but also below x contribute to types_below_u but not to types_in_(x,u).

To make this exact: use the fact that in a LINEAR ORDER, a point v with v < u and v > x IS in (x, u). So if sigma is realized by some v' < u' in M' and also by some v'' > x' in M', we need a SINGLE point that is both > x' and < u'. In a linear order, if there are sigma-points below u' and sigma-points above x', does it follow that there's one in (x', u')? NO -- the below-u' point might be below x', and the above-x' point might be above u'.

So approach (2) requires a more subtle argument. Possible refinement: use the 2-var NF (v, u) at depth k-1 which encodes v < u AND v's relationship to the carrier. Combined with the 2-var NF (v, x) at depth k-1 which encodes x < v. A point satisfying BOTH constraints must be in (x, u). And the depth-k NFs of u and x jointly encode which COMBINATIONS of 2-var NFs are simultaneously realizable.

This requires proving that the "simultaneous realizability" information is extractable from the depth-k 1-var NFs of x and u independently. This is a non-trivial lemma.
