## Implementation Roadmap (Revised — Canonical Pivot)

The roadmap from the previous handoff (cycle 3) remains valid but needs the following clarifications based on cycle 4 findings:

### Why the Canonical Pivot is Necessary

The backward game G_{n+1; r} requires n+1 coordinated responses. The forward game provides coordinated responses (single play = single strategy), but goes M->N (wrong direction). The IH (h_bwd_n) provides n coordinated responses N->M but cannot be extended to n+1 without cross-term consistency.

The canonical pivot resolves this by:
1. Choosing a split point c/d based on the forward game
2. Using restrict_left/restrict_right to extract COORDINATED sub-interval forward games
3. Applying IH to get COORDINATED sub-interval backward games
4. Splitting Spoiler's n+1 selections at d (each sub-interval gets <= n)
5. Each sub-interval's backward sub-game handles its group of selections

### Step 1: Establish h_d_consistent (Claim 1)

**Key**: For any carrier point c in M and d in N at rank R that agree on rank-R formulas, the forward game at (m, R) maps c to d whenever c is included in Spoiler's selections.

For DISCRETE orders, this follows from a simpler argument than the full GHR93 Claim 1:
- In discrete orders, all elements are carrier points
- Formula agreement at rank R between c and d is equivalent to: d2c(c) and d2c(d) satisfy exactly the same temporal formulas (rank-independent in discrete orders)
- The forward game's winning strategy preserves ALL rank-R formulas
- If Spoiler includes c, the response to c must agree on all rank-R formulas
- Since formula agreement uniquely determines the carrier point (up to rank-R formulas), the response must be d

**However**, formula agreement does NOT uniquely determine the carrier point in general. Two distinct carrier points can agree on all formulas up to rank R. So Claim 1 needs the specific construction of C = X_{alpha_n} ∧ not-U(not-A, T) to FORCE the response to be exactly d.

For the implementation, I recommend:

1. **Define the pivot semantically** (not syntactically): Given alpha_n in N (Spoiler's last point), define d = alpha_n (lifted to rank R). Define c via the forward game: use the 0-round forward game to find the unique c matching alpha_n at rank R.

2. **Prove h_d_consistent directly**: Show that for any forward game play at (m, R) where Spoiler includes extendPoint c, the response at c's position matches d. This uses:
   - `hord_fwd` from the forward game's winning condition (order preservation)
   - `hform_fwd` from the forward game's winning condition (formula preservation)
   - The fact that c is the UNIQUE response to d at rank R

3. **Apply restrict_left/restrict_right** at (1+3n, R) to get sub-interval forward games.

### Step 2: Sub-interval Forward Games (Claim 2)

From h_fwd at (4+3n, R), by round_mono get (2+3n, R). Using h_d_consistent, apply:
- `ghr93_strategy_restrict_left` -> forward game at (1+3n, R) on [x,c]/[x',d]
- `ghr93_strategy_restrict_right` -> forward game at (1+3n, R) on [c,y]/[d,y']

### Step 3: Apply IH

The IH at r' = r+4 converts:
- Forward (1+3n, (r+4)+4n) = (1+3n, R) on [x,c]/[x',d] -> backward (n, r+4) on [drc x',drc d]/[drc x,drc c]
- Forward (1+3n, R) on [c,y]/[d,y'] -> backward (n, r+4) on [drc d,drc y']/[drc c,drc y]

### Step 4: Convert to Rank r and Compose

For discrete orders, the backward sub-games at (n, r+4) transfer to (n, r) because:
- Order: carrier-point order is rank-independent
- Gap/point: all carrier points in discrete orders
- Formulas: stavi_truth_mu_at_point makes formula truth rank-independent

The rank-r backward sub-games can be composed via `ghr93_strategy_compose` (applied with N, M instead of M, N) to get a backward game at (n, r) on the full interval.

### Step 5: Case Analysis

**Case I** (alpha_0 < d): Both sub-intervals have <= n of Spoiler's n+1 points. The composed (n, r) backward game handles all n+1 points (distributed across sub-intervals, each with <= n).

**Case II** (all alpha_i >= d): All n+1 points are in [d, y']. The right sub-interval has n+1 points but the backward sub-game only handles n. The extra point (alpha_n) is handled via Until-formula transfer: since the backward sub-game preserves formulas at rank r+4, and U(B,A) has rank r+1 <= r+4, the Until witness gives the response for alpha_n.
