**Approach**: Since c is monotone, `c(castSucc kj) <= c(last m)`, so `c(last m) < c(castSucc kj)` is FALSE. Similarly `c'(last m) < c'(castSucc kj)` is FALSE. So `<` iff is trivial (both False).
