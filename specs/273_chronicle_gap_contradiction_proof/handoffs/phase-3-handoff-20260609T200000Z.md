### Sorry 1: Ordering Consistency (line ~985)
```
⊢ ∀ (i j : Fin n), (a i < a j ↔ a' i < a' j) ∧ (a i = a j ↔ a' i = a' j)
```
Current independent matching via `Classical.choose` on the FULL interval does NOT preserve pairwise ordering. Needs sub-interval-aware sorted matching.

**Fix**: Match elements in sorted order. For the k-th element in sorted order, match within sub-interval [prev_match, y]/[prev_match', y'] using `h_univ`. This ensures monotonicity. Equal elements get equal matches since `match_fn` is index-based (same carrier point -> same Classical.choose result).

### Sorry 2: Point Challenge (line ~987)

Needs to find b matching b' with winning condition on the FULL n-element game_tuple. The winning condition at parameter n requires formula agreement at all n+3 positions.

**Fix**: Route b' to the appropriate sub-interval [a'(σ(k)), a'(σ(k+1))] where b' falls. Extend to the full n-element winning condition using the already-proved type/ordering/gp properties.
