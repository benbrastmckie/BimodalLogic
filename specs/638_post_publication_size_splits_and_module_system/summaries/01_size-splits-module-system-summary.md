with every declaration moved verbatim inside the unchanged namespace
`FormalSystem.Metalogic.Expressiveness`. `EFGames/GapDetection.lean` became four flat modules;

durable document with the verdict "not now; its own programme; decision record first". Both

## Decisions

- Cut points were re-derived from section openers and declaration names, then enforced by
  assertions inside the generating script; the four-way and two-way verbatim-move `diff -B` checks
  were both empty before any docstring edit.
- Pre-edit probes confirmed the seams: F-right mentions F-left names only in prose; F-mu mentions
  no F-defs name; only F-mu declarations have consumers outside the original file; neither
  `private` helper is used outside F-defs, so both stay put and their mangled names are unchanged.
- Phase 5 (prose, no build) was closed before Phase 2 under cheapest-closure-first; one phase was
  open at a time throughout.
- The `longFile` baselines were computed as `(lines / 100) * 100 + 200`, the value the linter
  itself proposes; all three builds produced zero warnings, so the linter accepted them.
- The aggregator's docstring was left alone: it enumerates topics, not files.
- No status line was added to `PUBLICATION_REFACTOR.md`'s optional post-publication phase,
  because that phase carries none.
