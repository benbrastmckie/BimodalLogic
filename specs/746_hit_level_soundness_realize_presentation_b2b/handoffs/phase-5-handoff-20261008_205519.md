## Key Decisions

- **Ten fields, not six.** The plan's six clause groups each name two independent conditions in
  groups 1-4 (forward/backward seriality; `botFalse`/`impEq`; `UCoh`/`ULive`; `SCoh`/`SLive`), so
  they landed as ten named fields with the grouping recorded in `Cons`'s docstring. A six-field
  version would have had to bundle `UCoh` with `ULive` in a conjunction, which `cons_localRun`
  would then have to destructure at every use — the opposite of field-by-field.
- **`nowOnce` is stated over `StepPath`, not over an `ℕ`-indexed chain.** The plan's spelling is
  "no `step`-path of positive length from a `clNow`-labelled state returns to one", and
  `StepPath` (`Present.lean`) is this tree's existing notion of a finite `step`-path. The cost is
  that Phase 7 must build a `StepPath` from a stretch of the run to use it; the benefit is that
  no new path notion is introduced. `2 ≤ p.length` is "positive length" because a `StepPath`'s
  list carries one entry per state, so a zero-step path is the singleton.
- **`Cons` is not decidable as a bundle, and the docstring says so.** `impEq`, `ucoh`, `ulive`,
  `scoh`, `slive` quantify over `ψ χ : PlusFormula` (infinite) and `nowOnce` over `List Q`. The
  individual clauses are decidable at a given letter triple, which is what the test fixtures
  exercise. Deciding the bundle would need the finite quantification over
  `plusSubformulaClosure φ`; it is not built here and is not claimed.
- **The fixtures check the landed declarations, not copies.** Evidence probe
  `03_cons-non-vacuity.lean` re-spells `UCoh`/`deferGraph` inline because it predates the module.
  The permanent witness imports `…RaySummary.Realize` and passes the real `UCoh`, `ULive`,
  `deferGraph`, `SCoh`, `SLive`, `bwdDeferGraph` — so a future edit to any of those six
  definitions turns the test red. One added `import` line is the whole cost; annotated in the
  plan and logged in `issues.jsonl`.
- **One fixture pair covers both time directions.** `labCons` satisfies `UCoh`, `ULive`, `SCoh`
  and `SLive` simultaneously, and `labConsBad` (state `0`'s event removed, nothing else) breaks
  `ULive` and `SLive` simultaneously while leaving `UCoh` and `SCoh` true. This was designed by
  hand and then confirmed by 15 `#guard`s in a scratch file before either module was edited, so
  no fixture search was needed.
- **The `nowOnce` check is honestly scoped.** The depth-3 enumeration is a computed check on the
  fixture, not a witness of the `StepPath`-quantified field. The appended prose states the
  completeness argument (a path of more than three states on a three-element carrier repeats a
  state, so adds no endpoint the enumeration missed) as prose, and marks it as prose.
- **The `#guard`s are clause-level, not a `Cons` inhabitant.** `botFalse`, `impEq` and
  `boxStabFree` are conditions on a labelling over `clSig φ` for a concrete `φ`; everything the
  fixtures check is at a bare `sigCons` and so is shared by every `φ` whose closure supplies the
  three letters. The plan's task asked for exactly this, and the test prose names the gap rather
  than implying the bundle itself has been inhabited.
- **Trialled standalone before editing, twice.** Both the `Cons`/`cons_localRun` section and the
  whole fixture block were elaborated against the already-built oleans via `lake env lean` in the
  scratchpad. The proof section came out clean on the first attempt bar one `Bool.false_ne_true`;
  the fixture block came out clean on the first attempt. Each real module was edited exactly
  once. Same discipline Phases 3 and 4 recorded as a win.
