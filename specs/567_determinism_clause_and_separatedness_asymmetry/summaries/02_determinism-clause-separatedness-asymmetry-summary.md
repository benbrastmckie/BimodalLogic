## Decisions

- **The declared single-file scope could not hold the pair, and the obstruction is mechanical.**
  Followed the `.decisions.json` Option A siting: the biconditional in
  `Semantics/DeterministicBridge.lean` (whose transitive import of `ProofSystem.Axioms` is exactly
  what the `Presheaf/` lock forbids), the asymmetry in a new `Metalogic/Independence/` module. This
  mirrors the existing `PlusDeterminism` (choice-free) / `DeterministicBridge` (ZFC) split for
  `lem:deterministic-singleton`.
- **Separatedness is injectivity of every restriction map.** The cover-relative sheaf reading is a
  theorem about every task frame at no frame hypothesis, so under that reading the asymmetry result
  would read as false. Each new module says which sense is meant; the cover-relative form gets no
  declaration.
- **The open question is narrower than the task description stated.** A `BL⋆` characterization of
  separatedness on regular frames already exists (`deterministic_starDefinable` composed with the
  clause), and `L⁺` has none (`deterministic_not_plusDefinable`). What is open is whether a
  **choice-free** characterization exists. Posed in the docstring; not attacked.
- **`BehSeparatedness.lean` is deliberately not a thirteenth numbered Independence result.** It is a
  strictness result reusing result 5's `F°`, not an underivability result, which keeps
  `Independence/README.md` and `Independence.lean`'s reconciled twelve-item lists in step rather
  than renumbering both. Recorded in the README itself.

## Impacts

- The *Determinism* clause joins *Germs*, *Sheaf*, *Totality* and *Directed Gluing* as a discharged
  clause of `app:presheaf-dictionary`; five of the dictionary's clauses now have formal content.
- `Presheaf.Separated` is available as an interchangeable hypothesis with
  `TaskFrame.SingletonClasses` at any regular frame, so a consumer can state a condition on the
  behavior presheaf and get determinism, or the reverse, without re-deriving either.
- This is one of only two results running **from** this repository's semantics **to** the paper's
  category theory rather than the reverse, which is the point of the categorical front.
- The asymmetry gives a precise presheaf-side measure of the gap between a validity on a frame and a
  frame condition on it — the gap `determined_valid_on_non_deterministic` records at the frame
  level.
