- **Key decisions**
  - `size`'s empty cases are `0` (`sizeList .nil = 0`, `sizeObj .nil = 0`), as the plan requires:
    the naive measure fails the Phase 4 bound at the empty-array leaf (`[]` is two bytes).
  - `Canonical` carries only the no-duplicate-key clause. The plan's second clause (no raw
    control character in a string) is *not* needed: `escapeChar` escapes every character below
    `0x20`, so the printer never emits one, and the parser rejects one if it sees one. Recorded
    as a deviation on the plan's checklist item.
  - `escapeChar` emits `\u00XX` (lowercase hex) for control characters JSON does not name, so
    `unescapeBody` must decode that form for `unescape_escape` to hold on every input. It decodes
    `\u00XX` **only** for `XX < 20`; every other `\uXXXX`, including `A` and `é`, is a
    protocol error. That is what reconciles the settled "reject `\uXXXX`" decision with a
    total escape round trip.
  - Printers carry their closing bracket in the list/obj recursion (`printCJsonList .nil = [']']`),
    mirroring the validated spike, so the parser and printer recursions have the same shape.
- **Deviations**: the `Canonical` control-character clause, above. No others.
