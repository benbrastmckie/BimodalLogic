## What NOT to Try

- Do not route source-store commits through BimodalLogic's `git-commit-phase.sh`/
  `git-commit-scoped.sh`.
- Avoid embedding literal double-quote characters inside a `git commit -m "$(cat <<'EOF' ...
  EOF)"` heredoc body in this repo — `guard-destructive-git.sh`'s quote-stripping pass can
  mismatch on internal double quotes and produce a false `-a/-am` BLOCKED. Reword to avoid them,
  or use `git commit -F <tempfile>`.
