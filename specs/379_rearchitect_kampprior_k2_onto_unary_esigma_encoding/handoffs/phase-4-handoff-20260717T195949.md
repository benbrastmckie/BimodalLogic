## What remains for Phase 4 — the general-`r ≥ 1` gluing (part (b))

**Target theorem:** `augTarget_backward : augConjSat N env (augTarget ψ) → efSat N env ψ` for
general `r`, then package `augTarget_iff : efSat N env ψ ↔ augConjSat N env (augTarget ψ)` (with
`augTarget_forward`). Phase 7's Negation case needs the ↔.

**Construction recipe (all reusable pieces already landed in §6/§7):**
Build the global witness chain `x : Fin (ψ.n + 1) → N.carrier` pointwise. For each point
`p : Fin (ψ.n + 1)`:
- If `p` is pinned (`∃ k, ψ.pin k = p`): `x p := env k` (well-defined by `env_eq_of_pin_eq`).
- Else `p` lies in a maximal gap between the immediate pinned neighbours `lo` (largest pin `< p`)
  and `hi` (smallest pin `> p`): `x p := xᴸᴴ p` where `xᴸᴴ` is the witness chain of
  `pairProject ψ lo hi` (from `pairProject_pins`). Ends (`p` below all pins / above all pins) use
  the diagonal chain of the extreme pinned free var.

Then discharge the six `efSat` clauses:
1. **StrictMono.** Within a gap: `xᴸᴴ` is `StrictMono`. Across a pinned boundary: the boundary
   value is `env` and consecutive pinned env values are ordered by `env_lt_of_pin_lt`; a gap point
   and its neighbouring pinned point compare via the gap chain's monotonicity
   (`xᴸᴴ(pin lo) = env lo < xᴸᴴ p` etc.).
2. **Pins** `env k = x (ψ.pin k)`: immediate from the pinned-point branch of the definition.
3. **Point types** `unaryHolds (ψ.pointType j) (x j)`: pinned `j` via `pointType_holds_at_env`;
   gap `j` via the gap chain's own point-type clause (`x j = xᴸᴴ j` and `xᴸᴴ` realizes
   `ψ.pointType j`).
4. **Before / 5. Between / 6. After intervals:** each global open interval `(x i, x (i+1))` sits
   inside a single gap, so it coincides with (or is a sub-interval of) the corresponding pair
   chain's interval; transfer via `unaryHolds_subinterval` applied to the gap chain's interval
   clause. The end intervals use the extreme diagonal chain's before/after clauses.
