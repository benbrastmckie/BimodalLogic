## Critical Issues

### 1. Until/Since Chain Coherence — The Last Conceptual Obstacle

**Files**: `Theories/Bimodal/FrameConditions/Completeness.lean:333, 335, 347, 386, 388, 393, 491, 493, 498`
**Files**: `Theories/Bimodal/Metalogic/Algebraic/UltrafilterChain.lean:3936, 3946`

**Description**: The restricted-coherence architecture (Task 81) narrowed the original "all formulas, all families" gap to "`deferralClosure(root)` formulas, single SuccChain". Two sorries remain in `succ_chain_restricted_forward_F` and `succ_chain_restricted_backward_P` (UltrafilterChain.lean:3936/3946), plus six step-transfer sorries in the Until/Since backward cases and three `forward_until_since_coherent` sorries in `FrameConditions/Completeness.lean`.

**Mathematical core of the obstacle** (from ROAD_MAP.md:91–94 and task 89 research): The X-vs-G mismatch. In BX after T-axiom removal, `φ U ψ ∈ MCS` does not give `G(φ U ψ) ∈ MCS`, so Until/Since eventualities cannot be propagated through chain successors by the axiomatics alone. Six rounds of research (task 89, 99% confidence) have confirmed no BX axiom bridges this — eventualities must be resolved by model construction, not ordering propagation.

**Impact**: This is *the* conceptual blocker. Without it:
- `completeness_over_Int` holds only modulo these sorries
- `discrete_completeness_fc` inherits the gap via its reduction to Int
- Every frame-specific completeness theorem in `FrameConditions/` carries the same pair of sorries

**Recommended fix**: Two candidate strategies, both nontrivial:
   - **(a)** Quasimodel construction (Gabbay, Hodkinson, Reynolds 1994). Decouples eventuality resolution from linear chain construction. Task 89 identifies linearization issues from prior task 83 attempts.
   - **(b)** Henkin-style fair scheduling in the BFMCS construction: interleave F/P/U/S witness selection so every eventuality is visited. Requires proving termination/fairness at the chain level.

**Estimated effort**: 4–8h research spike + 30–40h implementation (task 89 estimate). Once closed, `Completeness.lean:160` and all downstream frame completeness theorems become sorry-free modulo the next item.

### 2. `bfmcs_from_mcs_temporally_coherent` — The Isolated Family-Level Sorry

**File**: `Theories/Bimodal/FrameConditions/Completeness.lean:137, 240`

**Description**: The single family-level temporal coherence sorry the restricted-path architecture was explicitly designed to isolate. The bundle-level coherence from `construct_bfmcs_bundle` is not enough; the truth lemma needs family-level (per-chain) coherence. ROAD_MAP.md:29–70 documents the two-path architecture (original vs restricted) and explains why this sorry is strictly narrower and more tractable than its predecessor.

**Impact**: This sorry is reached through `bundle_validity_implies_provability` → `completeness_over_Int`. Currently the code goes through the restricted path which reduces to Issue 1; the old sorry at line 137/240 remains reachable for the legacy path and must be closed or formally bypassed for a no-corners result.

**Recommended fix**: Either
   - Close it using the restricted-coherence infrastructure now available (reduce the family-level obligation to `restricted_temporally_coherent` + `deferralClosure` saturation), or
   - Remove the legacy path entirely and prove `completeness_over_Int` purely via `restricted_bundle_validity_implies_provability`. This is task 58's "Wire completeness to FrameConditions" work — currently `[BLOCKED]` on Issue 1.

**Impact**: BXCanonical is not currently on the critical path (ROAD_MAP.md and TODO.md category 2), but for a *fully adequate* representation theorem it is the most direct structural correspondence — an alternative canonical construction that could replace the SuccChain machinery. ### 5. Dense Completeness Requires Rat Canonical Model

**File**: `Theories/Bimodal/Metalogic/DenseCompleteness.lean:1`
**Task**: 68

**Description**: `dense_completeness_fc` cannot reduce to `completeness_over_Int` because Int is not densely ordered. Requires an independent canonical model construction over Rat (or an arbitrary dense linear order).

**Impact**: For full adequacy, the representation theorem must cover the dense frame class. Without this, the claim "TM is complete with respect to TaskFrames over totally ordered abelian groups" (ROAD_MAP.md:190) holds only for the discrete subcase.

**Recommended fix**: Construct a Rat-indexed BFMCS chain. Most of the restricted-coherence infrastructure should transfer, but existential witness selection must handle the density condition (between any two times there is another).

## The Representation Theorem Specifically

The *representation* theorem is stronger than bare completeness: it asserts a structural correspondence between proof-theoretic (MCS) and semantic (task-frame) objects. What the codebase has, and what it lacks, specifically for representation:

| Ingredient | Status | Location |
|---|---|---|
| Lindenbaum quotient → Boolean algebra | ✓ sorry-free | `Algebraic/LindenbaumQuotient.lean`, `BooleanStructure.lean` |
| Interior operators (modal semantics of □) | ✓ sorry-free | `Algebraic/InteriorOperators.lean` |
| Ultrafilter ↔ MCS correspondence | ✓ sorry-free | `Algebraic/UltrafilterMCS.lean` |
| Parametric canonical model (conditional) | ✓ sorry-free | `Algebraic/ParametricCanonical.lean`, `ParametricTruthLemma.lean` |
| Parametric representation theorem | ✓ sorry-free (conditional) | `Algebraic/ParametricRepresentation.lean` |
| BFMCS bundle construction (family level) | ✓ sorry-free | `UltrafilterChain.lean::construct_bfmcs_bundle` |
| Modal direction (□ forward/backward) | ✓ sorry-free | `UltrafilterChain.lean::boxClassFamilies_modal_backward` |
| **Temporal direction: G/H** | ✓ sorry-free (restricted) | `restricted_temporal_backward_G/H` |
| **Temporal direction: F/P** | ✗ 2 sorries | `succ_chain_restricted_forward_F/backward_P` |
| **Temporal direction: U/S eventualities** | ✗ 6 sorries | `FrameConditions/Completeness.lean` step transfers |
| **Family-level coherence (legacy path)** | ✗ 1 sorry | `bfmcs_from_mcs_temporally_coherent` |
| **Discrete Icc finiteness** | ✗ 1 axiom | `discrete_Icc_finite_axiom` |
| **Dense frame completeness** | ✗ 1 sorry | `dense_completeness_fc` |

The algebraic/parametric side is essentially done. Everything missing is on the **temporal chain** side and all of it points at the same underlying mathematical problem: **propagating eventualities (`F`, `P`, `U`, `S`) through a canonical linear chain in the absence of the T-axiom**.
