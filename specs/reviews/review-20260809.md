## Critical Issues

### C1. Frame definition has changed to a four-axiom presentation; Lean states three, and Nullity is no longer among the paper's axioms

**Files**: `FormalSystem/Semantics/TaskFrame.lean:152-191`; paper `\label{def:frame}`

The paper's current `def:frame` axioms are *Compositionality*, *Seriality*, *Limit*, and
*Spherical*. Lean's `TaskFrame` structure carries `nullity_identity`, `forward_comp`, and
`converse`.

Clause-level divergence:

| Paper clause | Lean state |
|---|---|
| *Compositionality* — biconditional: `w ⇒ₓ₊ᵧ v` iff `∃u. w ⇒ₓ u ∧ u ⇒ᵧ v` | `forward_comp`, the lax one-directional law with `0 ≤ x, 0 ≤ y` |
| *Seriality* — new | absent |
| *Limit* — `⋂_{x>0} (w)ₓ = {w}` | absent (three free-standing helper theorems only) |
| *Spherical* — new; Sd1 directed-intersection on the ball space of segments | absent; segments and fibers absent entirely |
| Nullity — **demoted to derived** (`lem:nullity`, from Seriality + Limit) | still a structure axiom |
| Occurrence — **demoted to derived** (`thm:occurrence`) | n/a |

**Impact**: The biconditional Compositionality directly reverses a decision recorded as settled
in task 420's description, which adopted the lax law and stated that equality "would
additionally assert interpolation, NOT adopted". Interpolation is now asserted. Any work
proceeding from task 420's spec would implement a superseded frame.

**Recommended fix**: Do not amend `TaskFrame` from the existing task specs. Re-derive the
target structure from the paper first — task 438.

### C2. Consequence quantifies over TOTAL histories, not the "maximal" histories the researched task targets

**Files**: `FormalSystem/Semantics/Validity.lean:79,103`, `Truth.lean:128-137`; paper
`\label{def:world-history}`, logical-consequence definition

Three distinct answers are live in the repository at once:

| Source | Histories quantified over |
|---|---|
| Lean (current) | arbitrary shift-closed `Omega : Set (WorldHistory F)`; box reads `∀ σ ∈ Omega` |
| Task 414 (researched target) | **maximal** histories — Mathlib `IsMax` under an extension order, reached by Zorn |
| Paper (authoritative) | **total** histories, `X = D`, termed *possible worlds*, written `H_F` |

Totality and maximality are not the same predicate. `thm:extension` (every task-constrained
function on a nonempty subset of `D` extends to a total world history) is what keeps the
totality restriction non-vacuous, and per the `app:gluing` footnote the directed case rests on
*Spherical* — so the frame change (C1) and the history change (C2) are **coupled**, not
independent.

**Impact**: Task 414's researched target predicate is wrong. Its machine-checked prototype is
partially salvageable as the engine behind `thm:extension`, but the predicate in
`TruthAt`/`valid`/`SemanticConsequence` must be totality.

**Recommended fix**: Task 438 fixes the target predicate before 414 is replanned.

### H2. Dependency cycle among 414, 415, 420 — and the wave generator conceals it

**File**: `specs/state.json`

Edges are `420 → 415`, `415 → 414`, `414 → 420`. Prior analysis found the cycle is an artifact
of task-level rather than phase-level edges: 420's helpers are already landed, so only 420's
phase 6 genuinely waits on 415.

`generate-todo.sh` does not report the cycle. It places 415 in wave 1 with `Blocked by: --`
even though 415 has unmet dependencies on 414, 420, and 438 — Kahn's algorithm cannot assign
cycle members, and the output silently presents one as ready to start.

**Impact**: A reader of `TODO.md` would conclude 415 is actionable. It is not.

**Recommended fix**: Corrected edge set is deliverable 5 of task 438. Separately, consider
making `generate-task-order.sh` emit a warning when Kahn's algorithm terminates with unassigned
nodes, rather than force-placing them — this is a reporting gap independent of the semantics
work, and is not in 438's scope.

### H3. This repo's prose is stale on both counts and is not usable as a secondary source

`typst/chapters/02-semantics.typ:62-64,149-150`

**Recommended fix**: Re-derive from the paper rather than patching. Covered by 438's
reconciliation table; the prose rewrite itself belongs to the re-issued downstream tasks.
