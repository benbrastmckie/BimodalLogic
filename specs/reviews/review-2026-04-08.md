### Sorry Classification by Root Cause

**Root Cause 1: G-lift incompatibility** (dominates)
- Until formulas `(φ U ψ)` cannot be included in Lindenbaum seeds
- `g_content(M) = {α : G(α) ∈ M}` and `G(φ U ψ) ∉ M` in general
- Affects: ALL step-transfer sorries, forward_until_since_coherent, until_persists_through_succ, BXCanonical Until/Since
- **This is one mathematical problem appearing as ~12 sorry sites**

**Root Cause 2: F-resolution scheduling** (partially solved)
- DovetailedChain has sorry-free bundle-level forward_F
- SuccChain restricted_forward_F still sorry
- UltrafilterChain Z_chain_forward_F still sorry
- **Dovetailed path bypasses this**; remaining sorries are redundant with dovetailed construction

**Root Cause 3: Dense canonical model** (independent)
- Int is not dense; Rat construction needed
- Completely orthogonal to Until/Since issues

## Viable Paths Forward

### Path A: Restricted Forward Until via Deferral Closure (unexplored)
If forward Until coherence were restricted to formulas in the deferral closure, the restricted chain's sorry-free forward_F *might* suffice. Task 84 research identified this as unexplored (confidence unknown).

### Path B: Simultaneous Well-Founded Induction (unexplored)
Prove forward_F and forward_Until simultaneously by induction on formula complexity. The circularity (`forward_F` needs `temporal_backward_G` which needs `forward_F`) might break if both are proven in a single mutual induction.

### Path C: Quasimodel Replacement (~2000 LOC, 50% confidence)
Replace Lindenbaum chain construction with constraint-satisfaction. This avoids the G-lift issue entirely but is a major rewrite. The GHR 1994 approach was investigated and has issues with linearization.

### Path D: Accept Forward Sorry, Publish With Backward
The completeness proof's critical path uses the **backward** direction of the truth lemma (semantic → syntactic). Backward Until coherence is available (parameterized). If step transfer can be closed, the forward sorry becomes non-load-bearing for the main completeness result, modulo the truth lemma's G-case dependency.

### Path E: Focus on FMP / Weak Completeness (task 82)
The FMP (Finite Model Property) path has **zero sorries** in Decidability/FMP. Task 82 (close 2 FMP TruthPreservation sorries) provides weak completeness independent of the chain coherence issues. This is the lowest-hanging fruit.

### Path F: Close Discrete Axiom (task 60)
`discrete_Icc_finite_axiom` is the only custom axiom. Closing it removes the "custom axiom" concern independently of completeness sorries.
