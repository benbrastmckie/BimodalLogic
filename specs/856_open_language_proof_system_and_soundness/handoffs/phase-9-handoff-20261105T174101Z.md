## Key decisions

- **Disjunct nesting is read off `OpenAxiom`, not off the BX numbering.** `linear_until` and
  `temp_linearity` carry the paper's right-associated disjunction; `linear_since` and
  `temp_linearity_past` carry the left-associated one. The Star file has both variants of each,
  so each of the four was transcribed from whichever Star theorem matches the nesting:
  `starValid_linear_until_paper`, `starValid_linear_since`, `starValid_temp_linearity_paper`,
  `starValid_temp_linearity_past`. Picking the wrong variant costs only the `.inl`/`.inr`
  routing, but it does not typecheck, so the pairing is recorded in the section docstring.
- The two blocks **interleave** in the inductive (`until_F`/`since_P` sit between `linear_since`
  and `temp_linearity`), so neither is a contiguous constructor run. Each is internally
  constructor-ordered; the aggregate docstrings say so, for Phase 11's `obtain`.
