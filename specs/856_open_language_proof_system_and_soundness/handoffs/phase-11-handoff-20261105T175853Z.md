## Key decision

**Every arm is a bare `exact`, with no `simp only [OpenFormula.reflectTime, ...]` normalisation** —
including in the reflect dispatch. Phase 10's handoff warned that per-arm `simp only` would
probably be needed, as it is throughout
`Conservativity/Star/StarAxiomValidity.lean`'s `starAxiom_reflect_time_validIn_min`. It was not.
The reason is architectural rather than lucky: this file's reflection helpers are stated as
`OpenValid (<the literal schema>).reflectTime`, which is syntactically what the dispatch's goal
is after `cases ax` beta-reduces the constructor index. Star's helpers instead state the *mirror
schema* at reflected parameters, which only a `reflectTime` normalisation can reach. Keeping the
helper shape aligned with the dispatch goal is what removed 71 `simp only` calls and the need for
`reflect_time_*` push-through lemmas on `OpenFormula` beyond the five it already has.
