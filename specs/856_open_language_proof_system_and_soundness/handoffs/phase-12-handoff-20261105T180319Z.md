## Two notes for Phase 13 and 15

1. **Namespace.** The plan's Challenge block writes `open_soundness_validIn` under
   `namespace FormalSystem.Metalogic`, and its verification line names
   `FormalSystem.Metalogic.open_soundness_validIn`. The declaration is actually at
   `FormalSystem.Metalogic.Conservativity.open_soundness_validIn`, beside
   `plus_soundness_validIn` and `star_soundness_validIn`, which are both in that same namespace.
   The Challenge block pins *signatures*; name and signature match. Phase 15's
   `docs/theorem-index.md` rows must use the fully-qualified name as it actually is.
2. **The `show` tactic is linted in this repo.** The `temporal_necessitation` reflection component
   first used `show OpenTruthAt M τ x (OpenFormula.allPast psi'.reflectTime)` to exploit a defeq;
   the build emitted `The 'show' tactic should only be used to indicate intermediate goal states
   for readability`, which `--wfail` CI would fail. Replaced by the named `rfl` lemma
   `openReflectTime_allFuture`. Declared in `OpenSoundness.lean` rather than beside `OpenFormula`
   so that `OpenLanguage/Formula.lean`'s module invariants stay untouched — the same placement
   decision `OpenFormula.kPlus`/`kMinus` and `OpenContext` already record.
