## Key Decisions

1. **Gadget 1's trace equality consumes only `IsRun`'s own `↔`.** Phase 5 built `labOf` so that
   gadget 1 reads nothing but `isNowState`, so the seam correspondence is the whole premise, and
   `inl_bwd_pre`/`inl_fwd_post`/`inl_run_pinned` are NOT premises of `runTrace_mem_of_isRun`.
   They are landed because the plan's route names them and because they are the record that the
   presentation admits no unclassified gadget-1 run. This is stated in the probe's own section
   header rather than left implicit. `inr_bwd_pre` IS consumed, by `inr_post_threshold`'s
   `z ≤ t` case.
2. **The threshold comes from `Nat.find`, not from a bound.** `inr_post_threshold` takes the
   least `n` with index `L + 2` at `t + n`; `inr_fwd_index` guarantees `n ≤ L + 1`. This produces
   no bound on `L` and implies none: `L` remains the unexhibited `Set.Finite.bddAbove` witness of
   `hitCl_eq_truncated`, and `jump_window_card`'s docstring says so explicitly.
3. **`jumpRun`'s index is `min … (L + 2)`** so the `Fin (L + 3)` membership needs no side
   condition; `jumpRun_val` proves the `min` is the identity on the intended range, so it is
   bookkeeping rather than a truncation of the construction.
4. **`omega` does not discharge an `Iff` goal in this toolchain.** Every
   `split_ifs <;> omega` over `<index> = c ↔ <time condition>` failed; the fix is to decompose
   the `Iff` first (`constructor <;> intro h <;> omega`, or `iff_of_false`/`iff_of_true` with
   per-side `by omega`). Related: `split_ifs` reduces a closed-literal branch such as
   `0 = L + 2` to `False`, so that branch wants `not_false`, and `omega` ignores an atom-free
   hypothesis such as `h : 0 = 1`. Recorded in the issue log.
