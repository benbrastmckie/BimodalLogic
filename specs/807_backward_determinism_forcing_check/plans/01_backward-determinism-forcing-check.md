## Lean Challenge Statements

All twelve declarations are Goals: the eight `theorem`s carry `sorry` bodies, and the four
`def`s precede the first `theorem` so nothing is swallowed into a `:= sorry` (the snapshot tool
counts a `def` as a declared identifier, so the definitions are named under Goals too). The
definitional bodies are part of the contract: `yest φ` is `φ S ⊥` and nothing else, `bdForce q` is `Yq → ⊡Yq` built from
`PlusFormula.imp`/`.stab`/`.snce`/`.bot`/`.atom`, `HistBwdDet` is Thomason's clause on `⟨τ⟩_t` at
one step, and `StepBwdDet` is unique predecessors. This block was compiled through
`lake env lean` at plan time: exit 0, eight `declaration uses 'sorry'` warnings and no other
diagnostic.

```lean
import FormalSystem

open FormalSystem.Syntax FormalSystem.Semantics FormalSystem.PlusLanguage
open FormalSystem.Metalogic.Decidability

namespace Probe807Forcing

/-- "Yesterday φ": `φ S ⊥`. On ℤ-time this holds at `(τ, t)` iff `φ` holds at `(τ, t - 1)`. -/
def yest (φ : PlusFormula) : PlusFormula := PlusFormula.snce PlusFormula.bot φ

/-- The candidate forcing formula `Yq → ⊡Yq`. -/
def bdForce (q : Atom) : PlusFormula :=
  (yest (.atom q)).imp (.stab (yest (.atom q)))

/-- Thomason 1984 §4 Def. 6(2), rendered on `⟨τ⟩_t`: histories sharing the state at `t` share
the state at `t - 1`. -/
def HistBwdDet (F : FrameOver intOrder) : Prop :=
  ∀ (τ σ : WorldHistory F.toTaskFrame) (t : ℤ),
    τ.state t = σ.state t → τ.state (t - 1) = σ.state (t - 1)

/-- Frame-level backward determinism: the one-step relation has unique predecessors. -/
def StepBwdDet (F : FrameOver intOrder) : Prop :=
  ∀ u v w : F.WorldState, F.step u w → F.step v w → u = v

variable {F : FrameOver intOrder}

theorem yest_iff (M : TaskModel F.toTaskFrame) (τ : WorldHistory F.toTaskFrame) (t : ℤ)
    (φ : PlusFormula) :
    PlusTruthAt M τ t (yest φ) ↔ PlusTruthAt M τ (t - 1) φ := sorry

theorem histBwdDet_of_valid (q : Atom) (h : F.toTaskFrame.PlusValidOn (bdForce q)) :
    HistBwdDet F := sorry

theorem valid_of_histBwdDet (hF : HistBwdDet F) (q : Atom) :
    F.toTaskFrame.PlusValidOn (bdForce q) := sorry

theorem valid_iff_histBwdDet (q : Atom) :
    F.toTaskFrame.PlusValidOn (bdForce q) ↔ HistBwdDet F := sorry

theorem histBwdDet_iterate (h : HistBwdDet F) (τ σ : WorldHistory F.toTaskFrame) (t : ℤ)
    (hst : τ.state t = σ.state t) : ∀ n : ℕ, τ.state (t - n) = σ.state (t - n) := sorry

theorem histBwdDet_of_stepBwdDet (h : StepBwdDet F) : HistBwdDet F := sorry

theorem stepBwdDet_of_histBwdDet [F.IsRegular] (h : HistBwdDet F) : StepBwdDet F := sorry

theorem valid_iff_stepBwdDet [F.IsRegular] (q : Atom) :
    F.toTaskFrame.PlusValidOn (bdForce q) ↔ StepBwdDet F := sorry

end Probe807Forcing
```
