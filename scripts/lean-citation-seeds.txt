# Seed list for scripts/export-lean-citations.py
#
# One fully qualified declaration name per line. `## text` opens a group; `#` opens a comment.
# A row about a *structure field* writes `Parent.Name#field`: a field opens no declaration span,
# so the parent is resolved and the field is carried through as metadata. See the exporter's own
# header for the full contract.
#
# This list is the reviewable input; `scripts/lean-citation-manifest.json` is generated from it and
# must not be hand-edited. Every name here must resolve to exactly one declaration or the exporter
# exits non-zero: a name that stops resolving is either a rename this repository made and never
# propagated to a consuming document, or a typo here.
#
# WHAT BELONGS HERE. Every declaration a consuming repository's adequacy argument cites, plus the
# inspection-only definitional residue that argument's transcription audit must read against paper
# text. Adding a name is cheap; the cost of a missing one is a citation nothing checks.
