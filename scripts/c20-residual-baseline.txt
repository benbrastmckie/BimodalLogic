# One row per (citer-path, category) pair: `<count> <citer-path> <category>`,
# where <category> is one of `residual` (the citation carries no declaration
# name), `unverifiable-decl` (the named thing is not declared, or is declared
# ambiguously, in the target file) or `unverifiable-file` (the cited filename
# is itself ambiguous or resolves to no live file).

# deliberately: an unrelated edit above a citation would otherwise manufacture
# a new finding. A pair whose live count exceeds this ceiling fails, as does a
# pair with a non-zero live count absent from this file entirely. A row whose
# live count is below its ceiling is reported for pruning and never fails.
# Never add or regenerate a row to quiet a new failure -- name the
# declaration, qualify the ambiguous path, or drop the line number and cite
# the name alone.
#
