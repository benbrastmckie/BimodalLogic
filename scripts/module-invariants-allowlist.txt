# Dotted names in markdown that C5 must not treat as module paths.
#
# C5 flags any `Bimodal.*` / `BimodalTest.*` path in non-specs markdown whose
# components are all capitalized and which does not resolve to a real module file
# or directory. That shape is indistinguishable from a fully-qualified NAMESPACE
# or DECLARATION name, which is what every entry below is. They are correct as
# written; the check simply cannot tell them apart from a module path.
#
# This is a permanent, documented exemption, not a debt ledger. Only add an entry
# after verifying with `grep -rn` that the name really is a live namespace or
# declaration. A genuinely stale MODULE path must be fixed, never allowlisted.
#
# One name per line; `#` starts a comment.
