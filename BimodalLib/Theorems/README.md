# Theorems

The registered theorems: one `register_theorem` line per closed derivation declared under
`FormalSystem/Theorems/`, outside its `ProofMode/` directory. The derivations stay where they
are; a line here registers one by reference.

A line is filed by the fragment and frame class its row computes: the directory is the
fragment, the file the frame class. `Enumerated/` is the exception in both respects: its
entries are generated rather than registered by reference, and they are filed together because
proof extraction is `Base`-only, so the pipeline's theorem half has no frame-class axis.

| Path | Description |
|------|-------------|
| `Complete.lean` | Runs `assert_registry_complete` over the published library; the build fails when a closed derivation is unregistered. Also runs `assert_proof_fragments_recorded` over the whole registry, and `assert_no_subsumed_entries BimodalLib.Theorems.Enumerated` over the machine-generated entries |
| `Boolean/` | Statements with no modal or temporal operator |
| `ModalBoolean/` | Statements with a modal operator and no temporal one |
| `TemporalBoolean/` | Statements with a temporal operator and no modal one |
| `ModalTemporalBoolean/` | Statements with both |
| `Enumerated/` | Machine-generated entries: the theorems the tableau pipeline admitted. Not hand-written; regenerated by `scripts/theorem-library-pipeline.sh` |
