# TemporalBoolean

Registered theorems whose statement is in the `TemporalBoolean` fragment. A file other than
`Base.lean` holds the theorems whose registered derivation is stated at that frame class.

| File | Description |
|------|-------------|
| `Base.lean` | Derivable at every frame class |
| `Dense.lean` | Stated at the dense class |
| `ZTime.lean` | Stated at the integer-time class |
| `RTime.lean` | Stated at the Dedekind-complete class |

*Last verified: 2026-11-23*
