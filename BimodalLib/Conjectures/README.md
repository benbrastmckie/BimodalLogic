# Conjectures

Statements registered as not yet established. Each is a constant of type
`BimodalLib.Conjecture`, which has no proof field.

| Path | Description |
|------|-------------|
| `Conservativity.lean` | The conservativity edges of the fragment lattice: four open, and five kept with status `derived` or `refuted` and a note naming the theorem that settled them |
| `ModalBoolean/` | Conjectures filed in the `ModalBoolean` fragment |
| `Enumerated.lean` | The non-admitted outcomes of the tableau pipeline, as one aggregate constant per (fragment, frame class, verdict) cell: 48 in all, bounded independently of how large the conjecture half is |
