# NomicLanguage — BL plus the nomic operator

This directory is a self-contained component at the library root. It defines the object language
obtained from BL (`FormalSystem/Syntax/Formula.lean`) by adding the one restricted modal that the
manuscript's subsection *Restricted Modalities* (`sub:RestrictedModalities`) introduces beside the
open-future and open-past modals:

```
φ, ψ ::= pᵢ | ⊥ | φ → ψ | □φ | φ U ψ | φ S ψ | ◈φ
```

`◈` (`nomic`) is the operator of **nomological necessity**. Its clause is `def:nomic-frame`'s item
*Nomological Necessity*: `◈φ` holds at `(τ, x)` iff `φ` holds at `(σ, x)` for every law-history
`σ ∈ H_F^{τ(x)}` — so the accessibility relation at `x` relates `τ` to the law-histories at the
world state `τ` occupies there.

The component is **semantic only**: no proof system, no axiomatization, no soundness or
completeness claim. The manuscript offers none for `◈`, exactly as it offers none for `▷` and `◁`.

## Why the component exists

The three results of the paper's nomic block are results about an object language, and the frames
they are stated over are **not task frames**: a `NomicFrame` carries one task relation per world
state, and `H_F = ⋃_w H_F^w` is the world-history set of no single task frame once the frame is
non-uniform. So the operator cannot be a constructor on `Formula` evaluated by `TruthAt`, and its
truth recursion cannot be an instance of the abstract clause layer in
`FormalSystem/Semantics/TruthClauses.lean`, every class of which binds `TaskFrame`,
`TaskModel F`, `WorldHistory F` and `F.Duration`. The component carries its own recursion and its
own clause lemmas; `NomicTruth.lean`'s docstring records that duplication with its cause.

The frame-level half of the appendix is **not** here. `thm:nomic-uniform`'s six conditions mention
no object language, no formula and no model, so they live in `FormalSystem/Semantics/Nomic/`
beside `lem:nomic-recovery`, which the (5)⇔(6) step consumes.

## Recorded exclusions

| Item | Status |
|---|---|
| An axiomatization, soundness or completeness result for `◈` | **Excluded.** The manuscript gives none, exactly as for `▷` and `◁`, and none is claimed here. Every result in this component is semantic |
| Truth-level conservativity over BL (`NomicTruthAt M τ x (ofFormula φ) ↔ TruthAt …`) | **Excluded, and not statable here.** `TruthAt` is defined over a `TaskFrame`; this recursion is defined over a `NomicFrame`, whose `H_F` is the world-history set of no task frame unless the frame is uniform. A bridge exists only under uniformity — condition (6) of `thm:nomic-uniform` says the frame then *is* a task frame — which would make conservativity a corollary of the collapse rather than a general fact. `ofFormula` and `ofFormula_injective` are retained as the syntactic half of the claim |
| The stability modal `⊡` in `NomicFormula` | **Excluded.** `prop:nomic-tense-free`'s fragment is exactly `{pᵢ, ⊥, →, □, ◈}`, and the paper deliberately leaves `⊡` out of it. Adding `stab` would force a decision the paper does not make — whether `⊡` belongs in the fragment — and would add a `nomicSatSet` clause for no result in scope |
| The dense-time case of `app:nomic-four` | **Excluded, open in the paper.** Its own commented remark leaves it open: BL has no duration-indexed tense operator, so a violation at a general duration cannot be localized at adjacent times, which is exactly what the one-step extraction needs. `NomicFour.lean`'s docstring records the ℤ-time hypothesis as load-bearing |
| A generalisation of `Semantics/TruthClauses.lean` over the point structure | **Excluded.** It would be a refactor across six language components. The duplication of the derived-operator clause layer is recorded with its cause in `NomicTruth.lean` instead |

## Choice dependence, recorded honestly

Every result here that reaches `NomicFrame.occurrence` (`lem:nomic-occurrence`) is a theorem of
**ZFC**, not of ZF: that lemma runs through `thm:extension`, whose proof appeals to Zorn's lemma.
`rmk:choice` lists the paper's choice-free results and `lem:nomic-occurrence` is not among them,
so nothing here is advertised as choice-free except where it is measured to be: the uniformity
collapse `nomic_iff_box_of_uniform` and the (4)⇒(1)(2)(3) direction of `thm:nomic-uniform`
measure at `[propext]`, take no regularity instance, and carry no constraints-consumed marker.

## Module Invariants

**Syntax before semantics within this directory**, exactly as in the sibling language components.
`Formula.lean` imports nothing from `FormalSystem/Semantics/` and no semantic module of any
language. Every file here has a layer in the `LANGUAGE_FILE_LAYERS` table of
`scripts/measure-refactor-partitions.py` — 0 for a syntax file, 1 for a semantic module — and
`bash scripts/check-metalogic-cycles.sh` fails if a layer-0 file of any language directory imports
a layer-1 file of any of them, or anything under `FormalSystem/Semantics/`. **A new file in this
directory needs a row in that table.**
